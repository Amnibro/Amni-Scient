AMNITEX RAILGUN

0.88 GB
OF VRAM HOLDS THE 1-BIT TIER OF A 7-BILLION PARAMETER MODEL. UNDER A GIGABYTE! THE EXACT REST WAITS ON NVMe.

THE PROBLEM

THE VRAM WALL

Here's the wall. Every AI model has billions of numbers (called weights), and they need to live in your GPU's memory to run.

A 7-billion parameter model needs 14 GB of VRAM at standard precision. A 70B model needs 140 GB. The biggest models need over 800 GB.

Most consumer GPUs have 8–24 GB. An H100, the datacenter workhorse, has 80 GB. The math doesn't work.

The usual fix? Buy more GPUs. Split the model across machines. Spend millions. Ouch.

WHAT I BUILT

So I built AmniTex Railgun. It splits those weights with an approach based on abstract algebra, a branch of pure mathematics.

Instead of rounding numbers and hoping for the best, Railgun keeps a tiny 1-bit index on the GPU and the rest on NVMe, and the round trip is exact.

What you get: the resident part of a 7B model is 0.88 GB (worked out from the 1.21 GB I measured for a 9B model). And when you need the original weights back? They come back perfectly. Not approximately. Perfectly. Limits: the NVMe residual is 1.75× the fp16 size today, so the total store is bigger. Running on the 1-bit tier alone is lossy, and its quality isn’t measured yet.

HOW IT WORKS (SIMPLY)

THE BOOK ANALOGY

Picture a 1,000-page book. Normal compression is like summarizing each chapter: handy, but you lose details.

Railgun is like keeping an index card on your desk and the full book on the shelf. The card is what fits in VRAM. Need a page exactly? Pull it from the shelf, and you get it word for word. Today the shelf copy is bigger than the original book (1.75×), so this saves desk space, not shelf space.

And the progressive tier system lets you choose: read the card alone for speed (R-only tier, lossy), or pull the full page when you need it (Full tier, exact).

STEP 1 — ROUTE

Algebraic Routing

Each weight is classified into a small set of discrete states using a mathematical structure with special properties. This routing layer lives in VRAM—just 1–2 bits per weight.

STEP 2 — REFINE

Progressive Layers

Residual errors from routing are captured in successive refinement layers (G, B channels), each adding precision. These layers can stream from fast NVMe storage on demand. The in-between tiers aren’t measured yet.

STEP 3 — RECONSTRUCT

Lossless Recovery

At the Full tier, the complete fp16 weight is recovered exactly. Not approximately—bit-exact. Measured: every tensor I’ve tried, including all 290 layers of a 0.5B model with byte-identical outputs.

WHO IS THIS FOR?

AI COMPANIES

Fit More Models per GPU

A 1-bit resident tier could let one card hold several models. On paper that’s up to 4× fewer GPUs for the same load. Measured: three 9B tiers allocated on one 16 GB card. Not measured yet: serving under load.

RESEARCHERS

70B on a Desktop, Someday

A 70B model’s 1-bit tier works out to 8.75 GB, which fits a workstation GPU. That’s arithmetic, not a run, and the 1-bit tier’s quality isn’t measured yet.

EDGE / MOBILE

AI on Consumer Hardware

A 7B model’s 1-bit tier is 0.88 GB, small enough for laptop-class VRAM. Not run on a laptop or phone yet. Measured speed: a 9B model on the 1-bit tier does 1.5 tokens a second.

CORRECTIONS THAT STICK

Same exactness idea, different place! Adam, my local AI assistant, has a closed-loop correction memory. When you correct it, the fix is stored as exact text, read back to check it landed, and the wrong answer goes on a block list.

Verify-after-write

Every learned fact is written to each memory store Adam has attached, then immediately recalled to confirm it landed. If the read-back doesn’t match, the exact-lookup copy is rolled back and the write is reported as not stored.

Anti-pattern suppression

A wrong answer you’ve corrected goes into a suppression set kept in a ledger file. Every recall tier skips a stored answer that matches it, and it never federates to other instances. It’s an exact-text match after case and spacing are normalized, so it blocks that answer, not every way of phrasing the same mistake.

Grounding on rewording

Corrected facts return instantly from an exact lookup. Ask a reworded question and a close enough match is injected as authoritative grounding. That steers the model hard, but it’s an instruction, not a filter, so it doesn’t guarantee the same error never comes back.
