QUESTIONS PEOPLE ACTUALLY ASK

Can I talk to Claude, Grok and Gemini in the same place?

Yes — and ChatGPT, Copilot, Cursor, OpenCode, and a local seat too. One question goes to every connected seat. You can read them side by side, or run One-at-a-time so each model sees what came before it.

Do I need API keys? Does Braid bill for tokens?

Usually neither. Braid drives the CLIs you’re already signed into, so a seat costs whatever that subscription costs. You can still paste API keys or add a local model. We don’t meter or resell tokens.

Can the models see each other’s answers?

In One-at-a-time and Squads, yes — that’s the point. In All-at-once they answer blind so you get an uncontaminated compare.

Does it work with local models like Ollama?

Yes. An Ollama model or the bundled Adam-3B sits at the same table as the cloud seats, with no per-token bill from us.

How much does it cost?

Open beta is $10/month or $102/year, locked for as long as you stay subscribed. There’s a $5 tester tier if you’ll send feedback. Teams are quoted by email. Cancel any time.

Why not build this myself, or use CrewAI / LangGraph / an agent IDE?

You can build it. The cost shows up as evenings and as token burn while you debug handoffs and seat failures. Most harnesses also keep you inside one vendor, or they re-meter every call through their API. Braid’s job is narrower: the seats you already pay for, in one room, reading each other when you want that. Spend the model budget on the work; use Braid for the table.

What platforms?

Windows and Linux are native binaries — Linux wants glibc 2.39+ (Ubuntu 24.04+, Fedora 40+). macOS is a small double-clickable Python bundle (python3 only); the first open may need right-click → Open for Gatekeeper. Keys and sessions stay on the machine.

Who sees my prompts?

Not Amni-Scient. Prompts go to the seats you chose. We see Stripe payment events and a licence check (key + machine fingerprint). Details: privacy policy.
