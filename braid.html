ONE QUESTION, EVERY SEAT

You already pay for more than one AI. Braid stops them being four browser tabs that never talk. Ask once and the question goes to every seat — then, if you want, each seat reads the answers before it and builds on them instead of repeating them.

SIDE-BY-SIDE OR SEQUENTIAL

Side-by-side gives every model its own column so you can compare them cold. Sequential passes the question down the line, each seat reading the ones before it. One toggle, same conversation.

YOUR SUBSCRIPTIONS, NOT OUR METER

Braid drives the CLI tools you are already signed into, so a seat costs what your existing plan costs. Bring pay-as-you-go API keys or a local Ollama model instead if you prefer. Keys stay in your environment — never stored, never transmitted to us.

IT REMEMBERS BEING WRONG

When a seat is corrected, the correction is written to a shared memory as an addressable cell. The next question pulls only the cells it needs — not the whole transcript — so the room stops repeating mistakes without dragging context along.

AGENTIC GRAPHS

Draw who answers whom. Fan one goal out to several workers, route their output to a reviewer and a verifier, and loop the whole thing back until it meets the goal or a set number of laps runs out.

MATH THAT RENDERS

LaTeX comes back rendered, not as raw backslashes. Long derivations stay readable and scroll on their own instead of breaking the column.

REAL TOOLS, REAL FILES

Seats run with their own tools in a shared working directory, so one can write a file and the next can read it. Code review works because both seats are looking at the same diff.

QUESTIONS PEOPLE ACTUALLY ASK

Can I chat with Claude, Grok and Gemini at the same time?

Yes. Braid sends one question to every connected seat at once. View the answers side by side in columns to compare them cold, or sequentially where each model reads the answers before it and builds on them.

Do I need API keys, or does Braid charge for AI usage?

Neither is required. Braid drives the CLI tools you are already signed into, so a seat costs whatever your existing plan costs. Bring pay-as-you-go API keys or a local model if you prefer — Braid never meters or resells tokens.

Can the AIs see each other's answers?

That is the point of the round table. In sequential mode each seat reads every answer before it and responds — agreeing, correcting, or building on top — instead of answering blind.

Does Braid work with local models like Ollama?

Yes. A local seat (Ollama models or the bundled Adam-3B) joins the same table as the subscription seats, at zero per-token cost.

How much does Braid cost?

Open-beta pricing is $10/month or $102/year, locked for as long as you keep the subscription. There is a $5/month tester tier and team pricing from $7 per seat. Cancel any time.

Why don't I just build this myself — or use another agent harness?

Build it yourself. You could — and the bill would show up in tokens and subscription burn, not just evenings. Wiring multi-model orchestration, sequential handoffs, seat failures, memory, and a room that keeps working costs more in model usage and plan spend while you reinvent it than sitting on a Braid seat and letting us carry the development cost.

Any other agent harness. CrewAI, AutoGen, LangGraph, OpenAI/Claude agent stacks, multi-agent IDE runners, custom orchestrators — most of them are still one vendor's agents under one roof, or they re-meter every token through their API. They do not put Claude, Grok, Gemini, and a local seat in the same room on the subscriptions you already pay for, with each seat reading the last. You pay harness tax and still juggle tabs (or burn API credits) to get a real multi-model braid.

Keep your AI budget for your work. Use Braid for the table.

What platforms does Braid run on?

Braid is a Windows desktop app today. Your keys and sessions stay on your machine — nothing is proxied through our servers.
