ONE QUESTION, EVERY SEAT

You already pay for more than one AI. Braid stops them being four browser tabs that never talk. Ask once and the question goes to every seat — then, if you want, each seat reads the answers before it and builds on them instead of repeating them.

⚇

SIDE-BY-SIDE OR SEQUENTIAL

Side-by-side gives every model its own column so you can compare them cold. Sequential passes the question down the line, each seat reading the ones before it. One toggle, same conversation.

🔑

YOUR SUBSCRIPTIONS, NOT OUR METER

Braid drives the CLI tools you are already signed into, so a seat costs what your existing plan costs. Bring pay-as-you-go API keys or a local Ollama model instead if you prefer. Keys stay in your environment — never stored, never transmitted to us.

🧠

IT REMEMBERS BEING WRONG

When a seat is corrected, the correction is written to a shared memory as an addressable cell. The next question pulls only the cells it needs — not the whole transcript — so the room stops repeating mistakes without dragging context along.

🔗

AGENTIC GRAPHS

Draw who answers whom. Fan one goal out to several workers, route their output to a reviewer and a verifier, and loop the whole thing back until it meets the goal or a set number of laps runs out.

∑

MATH THAT RENDERS

LaTeX comes back rendered, not as raw backslashes. Long derivations stay readable and scroll on their own instead of breaking the column.

🛠

REAL TOOLS, REAL FILES

Seats run with their own tools in a shared working directory, so one can write a file and the next can read it. Code review works because both seats are looking at the same diff.
