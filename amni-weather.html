BUILT TO COMPETE ON THE MAP

Amni-Weather is a browser-native weather map aimed at the same job as meteoblue’s interactive maps: dense multi-variable fields, smooth pan/zoom, and full control over coloration. Basemaps reuse the Amni-Drive tile stack — Esri satellite, OpenStreetMap, CARTO dark/light, OpenTopoMap — with a Rust/WASM field engine and live Open-Meteo models (demo offline path included).

Temperature, feels-like, dew point, humidity, precip, snow, wind speed/gust/dir, MSL pressure, clouds, visibility, CAPE, UV, radiation suite, soil temp, VPD, and ET₀.

CUSTOM COLORATION

Eight palettes (Thermal, Precipitation, Jet, Dust, Chlorophyll, Turbo, Grayscale, Inferno), reverse toggle, opacity, and manual or auto value ranges.

HOW IT WORKS

1. GRID SAMPLE

Live mode samples a regional lat/lon lattice through Open-Meteo’s multi-coordinate forecast endpoint for the active map center.

2. WASM FIELD BUILD

Points are IDW-gridded, optionally box-smoothed, then bilinear-upsampled to a dense field texture entirely in Rust/WASM (JS fallback if WASM is blocked).

3. COLORIZE

Palette LUTs map value ranges to RGBA with opacity and reverse controls. Legend and point probe stay unit-aware (SI/US).

4. GLOBE RENDER

Three.js draws the Earth mesh, atmosphere, graticule, and weather overlay with orbit controls for smooth interactive inspection.

DATA & HONESTY

Amni-Weather is a visualization and field-processing product. Live meteorology comes from Open-Meteo public forecast models — we do not claim to operate our own global NWP suite. The competitive surface is the map: smooth multi-layer interaction, customizable coloration, zoom, and a WASM-accelerated field pipeline you can trust to run locally.

Demo mode generates synthetic fields with the same engine so you can evaluate the UI and shaders without a network. When live fetch fails, the app falls back to demo automatically.
