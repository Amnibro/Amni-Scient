BUILT TO COMPETE ON THE MAP

Amni-Weather is a browser-native weather map for dense multi-variable fields, smooth pan/zoom, and full control over coloration. Basemaps reuse the Amni-Drive tile stack — Esri satellite, OpenStreetMap, CARTO dark/light, OpenTopoMap — with a Rust/WASM field engine, live Open-Meteo sampling (zoom LOD), a baked global pack for fast coverage, and a full point forecast panel when you drop a pin.

MAP LAYERS + LOD

Temperature, feels-like, dew point, humidity, precip, clouds, MSL pressure, wind, CAPE, UV, visibility. Zoom densifies the live lattice; far-out stays light so the map stays snappy.

POINT FORECAST

Drop a pin for Now / Hourly / 7-day / Surf / UV·Air tabs — WMO icons, sparklines, marine waves when available. Refresh on demand; no account required.

HAZARDS

US NWS alerts plus global GDACS Orange/Red severe events (storms, floods, volcanoes, wildfires, drought, quakes, and more).

CUSTOM COLORATION

Palette presets, reverse, opacity, gamma, soft mask, auto or manual ranges — paint the field the way you want to read it.

SLIPPY MAP UX

Fractional zoom, inertia pan, pinch on mobile, wind streamlines, pressure isobars, city labels + borders. Locate via browser geo, then IP fallback; last place remembered.

RUST / WASM ENGINE

IDW gridding, upsample, smooth, field stats, and palette work compile to WASM with a JS fallback if WASM is blocked.

LIVE + PACK

Always-on live path with silent pack/global-field fallback when APIs are busy. No fake “demo mode” switch — the map should never brick.

PRIVACY-HONEST

No accounts. Processing stays in your browser. Prefs (place, units) in localStorage only. Live fetches go to Open-Meteo, map tiles, and public hazard feeds — see the privacy page.

HOW IT WORKS

1. LOCATE & SAMPLE

World view until you search or allow locate. Live mode samples a lat/lon lattice through Open-Meteo for the active viewport; density follows zoom LOD.

2. WASM FIELD BUILD

Points are IDW-gridded, smoothed, and upsampled to a dense field texture in Rust/WASM (JS fallback if WASM is blocked). Pack fields fill gaps fast.

3. COLORIZE & OVERLAY

Palette LUTs map value ranges to color. Wind trails and isobars sit on the slippy basemap with unit-aware probe chips.

4. PIN FORECAST

Click the map for a pin: forecast panel loads hourly/daily/surf/UV·air for that point while hazards stay in view.

DATA & HONESTY

Amni-Weather is a visualization and field-processing product. Live meteorology comes from Open-Meteo public forecast models — we do not claim to operate our own global NWP suite. Alerts come from NWS and GDACS public feeds. The competitive surface is the map: smooth multi-layer interaction, customizable coloration, pin forecasts, and a WASM-accelerated field pipeline that runs in your browser.

When live fetch is rate-limited or offline, the app falls back to baked pack / global fields so the UI stays usable. We do not ship a separate “demo mode” product path.
