Is it really Arch?

Yes. Amni OS uses the Arch repositories plus one of its own, [amnios], for the Amni apps, the desktop and a few things that are not in Arch (Calamares, the Secure Boot shim). pacman, the Arch Wiki and the AUR all apply.

Does it keep Windows?

The installer's default is Install alongside, which shrinks Windows and adds Amni OS next to it. Windows stays in the boot menu. See the install guide for BitLocker and Fast Startup.

Does it work with Secure Boot?

An installed system does, after a one-time key enrollment on the first boot. The live USB is easiest with Secure Boot off. How it works.

What updates automatically?

Amni packages (the desktop, Amni-Browse, Haven, Mail and the rest of the suite) and Flatpak apps update daily. Full Arch updates wait for you to press Check updates in Amni Control or Discover. Set SCOPE=all or SCOPE=off in /etc/amni-os/update.conf to change that.

Can I undo an update?

Yes. Every package change takes a restore point before and after, and you can boot any of them from the menu. Restore points.

Does Amni OS collect data?

No. There is no telemetry, no account and no analytics. The network connections it makes on its own are listed on the privacy page.

Which graphics cards work?

AMD and Intel with Mesa, NVIDIA GTX 16xx and RTX cards with the open NVIDIA driver, and older NVIDIA cards with nouveau. Drivers.

Can I play my Steam games?

Steam, Proton, Wine and Lutris are on the image. Most Windows games run through Proton. Games with kernel anti-cheat usually do not.

Where do apps come from?

Discover installs from the Arch repositories and Flathub. Snap works out of the box, and distrobox gives you Ubuntu or Fedora boxes for software that only ships as .deb or .rpm. Double-clicking a .deb or an app tarball installs it too.

How much space and memory does it need?

The installer asks for 20 GB of disk and 3 GB of RAM. More of both makes it nicer; games and local AI models want a lot more disk.

Where do I report a bug?

On GitHub issues, with the output of amni-bug-info. For questions, the Haven community is quicker. Support has both.
