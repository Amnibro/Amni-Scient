INSTALL AMNI OS

Updated 25 Sep 2026

Amni OS is Arch Linux with Plasma 6, set up for people coming from Windows. This page takes you from the download to a first login. The other guides cover what happens after that.

Restore pointsSnapshots around every update, bootable from the menu. DriversHow Amni OS picks graphics and device drivers. TroubleshootingBlack screens, Wi-Fi, updates, sound. SupportHaven community, bug reports, amni-bug-info.

What you need

  • A 64-bit PC (x86_64) that boots UEFI or legacy BIOS.
  • At least 3 GB of RAM and 20 GB of free disk space. The installer checks both.
  • A USB stick of 8 GB or more. Writing the image erases it.
  • A network connection for the install is optional, but updates and some first-login apps need one.

1. Download

Get the ISO from the Amni OS page. Each release on downloads.amni-scient.com/amni-os/ sits next to its checks:

FileWhat it is
amni-os-<version>-x86_64.isoThe image you write to the USB
.iso.sha256SHA-256 checksum, catches a broken download
.iso.minisigminisign signature, proves the image came from us
.iso.torrentThe same image over BitTorrent
latest.jsonVersion, size, checksum and signature links of the newest release

2. Verify the ISO

A checksum tells you the file arrived intact. A signature tells you who made it. Do both if you can.

Checksum

sha256sum -c amni-os-<version>-x86_64.iso.sha256

On Windows, in PowerShell, compare the output with the .sha256 file:

Get-FileHash .\amni-os-<version>-x86_64.iso -Algorithm SHA256

Signature (minisign)

Amni OS images are signed with minisign. The public key is:

RWSDVMnkyKyF+mOSqdNRaQ/onOP7h3SUNpmOgmRSYNl9Td5vE3VIyfzM

It is also in amnios-iso.pub (a copy of branding/amnios-iso.pub in the Amni OS source) and in the minisign_pubkey field of latest.json. Put the .minisig file in the same folder as the ISO, then run:

minisign -Vm amni-os-<version>-x86_64.iso -P RWSDVMnkyKyF+mOSqdNRaQ/onOP7h3SUNpmOgmRSYNl9Td5vE3VIyfzM

minisign is pacman -S minisign on Arch and in most Linux repos. On Windows, download it from the minisign page and run the same command. A good image prints Signature and comment signature verified. Anything else means do not use that file: download it again, and tell us if it still fails.

Older images published before signing started have only the .sha256. Signed images carry a .minisig beside them.

3. Write the USB

Windows

  • Rufus: pick the stick and the ISO, press Start. If Rufus asks, choose Write in DD Image mode.
  • Ventoy: install Ventoy on the stick once, then copy the ISO onto it. The stick keeps working as normal storage.

Linux

Find the stick with lsblk first. Writing to the wrong device wipes it.

sudo dd if=amni-os-<version>-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync

KDE ISO Image Writer and GNOME Disks do the same thing with a window.

4. Secure Boot

An installed Amni OS boots with Secure Boot on. The live USB is simplest with Secure Boot off.

  1. Before booting the USB, turn Secure Boot off in your firmware settings (or use Ventoy and enroll its key when it asks).
  2. The installer puts a Microsoft-signed shim on the disk, creates a key that belongs to your machine, signs GRUB and the kernels with it, and queues that key for enrollment.
  3. On the first boot after installing, a blue MokManager screen appears once. Choose Enroll MOK, Continue, Yes, type the password amnios, then Reboot.
  4. Now you can turn Secure Boot back on. Kernel and GRUB updates are re-signed automatically.

If you missed the MokManager screen, run sudo /usr/lib/amni-os/secureboot-setup and reboot to get it again. The same key is also on the EFI partition as ENROLL_THIS_KEY_IN_MOKMANAGER.cer.

5. Boot the USB

Plug the stick in and open your PC's boot menu (usually F12, F11, F8 or Esc right after power on). Pick the USB entry, the UEFI one if there are two. The menu has:

  • Amni OS live: the normal choice.
  • Amni OS live (safe graphics): use this if the screen stays black or freezes on the logo.

6. Install

Click Install Amni OS. It is on the live desktop, first on the dock, and in a banner in Amni Control. The installer (Calamares) walks through:

  1. Location and keyboard. Pick your time zone on the map. The installer never looks up your location online, so it starts at New York.
  2. Partitions. Install alongside is the default and keeps Windows: drag the divider to choose how much space Amni OS gets. Erase disk uses the whole drive. Manual partitioning is there if you want it.
  3. File system. Btrfs is the default and is what makes restore points bootable. ext4 and XFS work too; on ext4, Timeshift takes the restore points instead.
  4. Your account, then Install. When it finishes, reboot and remove the stick.

Installing next to Windows: if BitLocker is on, have your recovery key ready before you shrink the Windows partition, and turn off Windows Fast Startup so the disk is cleanly shut down. Windows stays in the boot menu afterwards.

7. First boot

  • The graphics driver for your card is set up automatically, and the driver rules install what the rest of your hardware needs.
  • If a boot never reaches the desktop, the next one starts in safe graphics and Amni Control offers Use full graphics once you are logged in. See troubleshooting.
  • At your first login, Spotify and Chrome (from Flathub) and a few AI coding tools install in the background. The privacy page lists what connects where and how to skip it.
  • Amni packages update themselves daily. Full Arch updates stay a click in Amni Control or Discover.
