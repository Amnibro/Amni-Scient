SUMMARY

  • Cantilever bending stress one depth from the wall: +0.25 % vs M(x)c/I; within 0.28 % at every level.
  • Plate with a hole, peak stress: −1.09 % vs Peterson’s Kt; within 3.44 % at every level.

METHODS

  • Amni-CAD static solver, source commit c3b1d7c5, Node.js 24, CPU backend; every solve converged below 10−6 relative residual.
  • 8-node hexahedron with incompatible modes (QM6); mesh targets 7k to 112k elements.
  • Stress is nodal von Mises as shown in the app; solve time is wall clock.
