HEADLESS API

SCRIPT AMNI-CAD ON YOUR OWN COMPUTER • INCLUDED WITH PRO • NOTHING UPLOADED

START FREE → PRICING

WHAT IT DOES

The headless API is the Amni-CAD engine without the editor. It runs as the amnicad command and as an HTTP API on your own computer, so scripts, build servers and other programs can build parts and run studies with no browser open.

  • Build parts from an Amni-CAD document (JSON) or a STEP or BREP file, and get size, volume, mass and every face
  • Export STEP, STL or BREP
  • Stress, vibration and heat with fixed, roller, prescribed, spring and stop supports, and force, pressure, torque, remote and bearing loads, on whole faces or on just a circle, rectangle or outline drawn on a face
  • Flow: drag, lift and drag coefficient in air or water
  • Nonlinear: large deflection, plasticity and contact between bodies
  • Make: instant quotes, flat DXF and G-code with your own machines and tools

Your designs are computed on your computer and are never uploaded. The command contacts amni-scient.com only to download the engine and its updates (every file is checked against a SHA-256 checksum), and to renew your license key.

SET IT UP

You need Node.js 20 or newer on Windows, macOS or Linux, about 30 MB of disk, and an Amni-CAD Pro or Enterprise license key. Copy your key from Pro in Amni-CAD (Copy key), or from the page that opens after checkout.

curl -fsSLO https://amni-scient.com/cad/api/amnicad.mjs node amnicad.mjs activate AMNIPRO1.your-key node amnicad.mjs serve

The first command that needs the engine downloads it. serve listens on http://127.0.0.1:41800/v1/. Run node amnicad.mjs help for every command.

HOW THE LICENSE TOKEN WORKS

  • Your key is the token. It is a license signed by the Amni-CAD license server, naming your plan, seat count and paid-through date. activate checks the signature on your computer and saves the key in your user settings folder, readable only by you.
  • Renewal is automatic. In the last 10 days of each billing period, the command sends only the key to the license server, which checks your subscription with Stripe and sends back a fresh key. Nothing else about you or your work is sent.
  • Cancel anytime. When a subscription ends, the API keeps working through the period you paid for plus a 7-day grace period, then stops until you renew.
  • Seats. Pro covers one person and Enterprise covers up to 10. A key isn’t locked to one computer; each person may use it on the computers they work on.
  • A separate local token protects the HTTP API from other programs and web pages. It is created on first use, stored next to the key, and printed by node amnicad.mjs token. Send it as Authorization: Bearer <token>. The server answers only on 127.0.0.1 and refuses requests addressed to any other host name.

A STRESS STUDY

curl -s http://127.0.0.1:41800/v1/stress \ -H "Authorization: Bearer $(node amnicad.mjs token)" \ -H "Content-Type: application/json" -d '{ "doc": {"units":"mm","material":"al6061", "features":[{"id":"a","type":"box","w":100,"d":10,"h":10,"x":50}]}, "sim": {"supports":[{"faces":{"side":"-X"},"type":"fixed"}], "loads":[{"faces":{"side":"+X"},"F":[0,0,-100]}], "res":"standard"}}'
  • Pick faces with {"side":"+Z"} (the outermost faces on that side), {"normal":"-X"} (every face pointing that way), {"type":"cylinder"}, {"pts":[[x,y,z]]} (the face nearest each point), or face numbers from /v1/build.
  • Supports: fixed, roller, disp with "d":[dx,dy,dz], spring with "k" in N/mm, and stop with "gap" in mm.
  • Loads: "F":[x,y,z] in N, "p" in MPa, "M":[x,y,z] in N·mm, "at":[x,y,z] for a remote load, "dist":"bearing" for a pin in a hole.
  • Study type: "type":"static" (the default), "modal" or "thermal". Mesh "res": quick, standard, fine or ultra.
  • Lengths follow doc.units; forces and stresses are always N and MPa.

WITHOUT A SERVER

{"op":"stress","doc":{...},"sim":{...}} node amnicad.mjs run job.json --out result.json

op is build, export, stress, flow, nonlinear, quote, dxf, toolpath, art or review. Files (STEP, STL, DXF, zip, PNG) are written to --out.

A GAME-READY ASSET

{"op":"art","glb":"knight_sculpt.glb","kind":"humanoid","size":2048} node amnicad.mjs run knight.json --out knight.zip
  • One call does the asset pass: decimates the sculpt to the triangle budget, unwraps and packs UVs, bakes tangent-space normals, ambient occlusion, base color, roughness and metal from the source (its textures or vertex colors), and writes LOD1 and LOD2 with their own UVs and smaller textures.
  • Characters come rigged. Humanoids get a 22-bone skeleton with standard names (Hips, Spine, LeftArm, RightUpLeg and so on), skin weights from geodesic distance through the body, and idle, walk, run, attack, cast, aim, hit and death clips. Quadrupeds get a 19-bone skeleton with idle, walk, run, attack, hit and death. Sculpt characters in an A-pose with the arms clear of the body for the cleanest weights; pass joints to place any joint yourself.
  • Two sources: send the full-detail sculpt as glb and a lower, painted copy as paint to bake shape detail from one and color from the other.

VAULT AUTOMATION (ENTERPRISE)

With an Enterprise key, the amnicad command can join your team vault and check files in for you. Run it on a build server or any computer that saves CAD files. It has its own vault key, so an admin approves it once in Amni-CAD under Vault, like any teammate.

amnicad vault join "<invite link>" --name "Build server" amnicad vault watch ./released --every 7 amnicad vault add bracket.step drawing.pdf --note "From supplier" amnicad vault ls bracket amnicad vault get PRT-000012 --what all --out ./out amnicad vault status

watch checks in every new or changed STEP, Amni-CAD, PDF, STL and DXF file under the folder. A changed file becomes the next revision of the same item, and files that have not changed are skipped. An assembly STEP is split into an assembly and its parts. An Amni-CAD file is built into a STEP by the engine and stored with its native file. Files are encrypted on the computer before they are sent. Add --once to check the folder one time, for scheduled jobs.
