AMNITEX — PRIVACY POLICY

Effective Date: November 21, 2026  |  Last Updated: November 21, 2026

AmniTeX (atex) is a local MCP server and command-line tool published by Amniscient, LLC. This page describes what the software does with data, from the v0.4.8 source. Questions: privacy@amni-scient.com.

It runs on your computer

AmniTeX does not require an account. Amniscient does not receive your project files, conversation text, or search queries. There is no telemetry and no analytics in the program.

What it processes

The MCP server (stdio) and the atex CLI read:

  • Files you index with atex init (project docs and code, up to 512 KiB per file)
  • Facts you or the assistant store with atex remember / atex_remember
  • Conversation turns that the installed hooks save
  • Search, where, and recall queries the assistant sends to the local server

That work happens on the machine that runs atex.

Where it is stored

The knowledge base is a folder on that machine. The default is, in order: the ATEX_DIR environment variable if you set it; ./.atex if that directory already exists; ~/ai/.atex if that directory already exists; otherwise ~/.atex (%USERPROFILE%\.atex on Windows). Inside it:

  • pages/ — the byte-page store
  • index.json — the key index
  • manual/ — user-taught facts
  • update/ — update checks; the daily-update log is update/log

The installer puts the binary in ~/.local/bin (%USERPROFILE%\.local\bin on Windows) and may add that folder to your PATH in your shell startup file. Deleting the knowledge-base folder removes the stored text. Uninstalling removes the client wiring described below.

Client wiring

atex install writes MCP server entries and hooks into AI apps it finds on your account, including ~/.claude.json, ~/.cursor/mcp.json, ~/.gemini/settings.json, ~/.codex/config.toml, ~/.grok/config.toml, Windsurf’s MCP config, and Claude Desktop’s config under ~/.config/Claude/, macOS Application Support, or %APPDATA%\Claude\ on Windows. atex uninstall removes that wiring.

Network

The only network use is optional self-update. About once a day, when an AI app starts atex serve, atex may download SHA256SUMS, SHA256SUMS.sig, VERSION, and the platform binary from the GitHub Releases URL (or from ATEX_UPDATE_URL if you set it). A new binary is installed only when the sums file is signed by the release key built into atex, the file matches its checksum, and atex --selftest passes on your machine. GitHub can see that request, as with any other release download. atex update --off or ATEX_NO_UPDATE=1 turns the check off.

Visiting amni-scient.com/amnitex or downloading the installer from that site is an ordinary page request. The site is hosted on Cloudflare, as described on the main privacy page.
