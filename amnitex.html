AMNITEX

SAVE CONTEXT AND TOKENS IN CLAUDE CODE, CURSOR & OTHER AI CODING ASSISTANTS • FREE & LOCAL • WINDOWS, MAC & LINUX

INSTALL FREE → GITHUB

WHAT IT DOES

Every reply from an AI coding assistant re-reads the whole conversation, so a long session gets slower and more expensive, until the assistant compacts it and loses details. Amnitex (the atex program) keeps that context small. It runs on your computer, needs no account and sends nothing anywhere.

COMPACTS SOONER

Sets Claude Code to compact at about 250K tokens, and at about 67K on Claude Haiku 5.5, before its price per request jumps. After /clear or a compaction it puts your last three turns back.

KEEPS LONG OUTPUT ON DISK

When a command prints thousands of lines, the assistant sees the start, the end and the error lines, plus the path to the full output.

FINDS THE LINES, NOT THE FILE

The assistant asks which file and line holds something and reads just those lines. In the lookup benchmark that took 94–96% fewer characters than reading whole files.

REMEMBERS EVERY TURN

Each finished turn is saved word for word on your computer, so an earlier port, hash or rule is looked up exactly instead of explained again.

INSTALL

One command installs the atex program, adds it to your PATH, runs a self-test and wires every AI app it finds: Claude Code, Claude Desktop, Cursor, Windsurf, Gemini CLI, OpenAI Codex and Grok Build. There is nothing to compile and no account to make.

WINDOWS

Paste into PowerShell. No WSL or administrator rights needed. Windows 10 and 11, including Windows 11 on ARM.

irm https://amni-scient.com/atex-install.ps1 | iex

MAC

Paste into Terminal. Apple Silicon (macOS 11 or newer) and Intel (macOS 10.15 or newer). No Xcode tools needed.

curl -fsSL https://amni-scient.com/atex-install.sh | sh

LINUX

curl -fsSL https://amni-scient.com/atex-install.sh | sh

Then restart Claude Code, Claude Desktop or Cursor. Check the wiring any time with atex doctor. atex uninstall removes it and leaves what Amnitex has stored in place.

CLAUDE CODE PLUGIN

After the install command above, you can also add the plugin from Claude Code:

/plugin marketplace add Amnibro/amnitex /plugin install amnitex@amnitex-marketplace

QUESTIONS

Is it free?

Yes. Amnitex is MIT-licensed and the source is on GitHub. There is no account, plan or license key.

Does it send my code anywhere?

No. Everything Amnitex stores stays in a folder on your computer (~/.atex). The installer downloads the program from GitHub, and that is the only time it goes online.

What does it change in Claude Code?

It registers its MCP server and adds three hooks and a compact window to ~/.claude/settings.json. Everything else in that file is kept, and the old file is saved as settings.json.atex-backup. atex install --no-compact-window leaves the compact window alone, and atex uninstall takes it all out.

How is it different from a vector database or a memory plugin?

It uses no embeddings and no model. Lookups are exact, so a port, a hash or a rule comes back byte for byte, and a 15 MB knowledge base loads in 22 ms.

Is this the same as AmniTex Railgun?

No. AmniTex Railgun is separate research on fitting AI model weights into less GPU memory, offered under evaluation licenses. Amnitex, on this page, is the free context saver for AI coding assistants, and it needs no license.

Where are the details?

The README covers every setting and measurement, and the conversation store benchmark has the earlier recall tests.
