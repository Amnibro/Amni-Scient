Commands

Run gold with no arguments to print this list in short form. Options use the form name=value.

CommandWhat it does
gold buildTranslate, check and write the Helium.
gold runBuild, then run the program.
gold showBuild, then print the Helium.
gold testBuild, then run the test commands of every pack it uses.
gold portWrite Gold for existing code in any language, then build it.
gold packIndex a product's Helium functions so Gold can call them.
gold packsList the indexed packs.
gold findShow which functions a sentence would retrieve.
gold compactPack data tables without a model call.
gold squeezeRewrite the Gold as shorter plain English and keep it only if it still passes.
gold lintList lines that read as code instead of English.

Build and run

gold build

gold build file.gold

Translates the paragraphs that changed, checks the whole file with the Helium compiler, and writes the Helium next to the Gold file, or to the into path from its header. Results are cached in file.gold.lock, so an unchanged paragraph never calls the model again. Commit the lock file with your code.

gold run

gold run file.gold [-- program arguments]

Builds the file, then runs the program. Everything after -- goes to your program.

gold show

gold show file.gold

Builds the file, then prints the Helium it produced.

gold test

gold test file.gold

Builds the file, then runs the test command of every pack named on its use line.

Bring in existing code

gold port

gold port source [use=pack,pack] [into=file] [lang=amni|he|py] [ns=name] [gold=out.gold]

Reads code in any language, writes the Gold that describes it, and builds that Gold.

OptionMeaning
use=Packs the new code may call, separated by commas.
into=The Helium file to write.
lang=The Helium flavor to write: amni, he or py.
ns=The namespace for the new code.
gold=Where to save the Gold. By default it sits beside the source, named after it.

gold squeeze

gold squeeze file.gold check='command' [rounds=4]

Rewrites the Gold as shorter plain English. Each shorter version is rebuilt from scratch and kept only when it rebuilds and your check command exits with 0. Use a check that also watches speed, so a shorter version can never make your program slower.

gold lint

gold lint file.gold

Lists every line that reads as code: operators such as == or &&, function signatures and Helium types. gold build refuses these lines in paragraphs that changed. Set GOLD_LINT=warn to build anyway.

gold compact

gold compact file.gold

Packs the data tables in a file, with no model call. It adds a first @ row of column scales, and a blank cell repeats the cell above. See data tables.

Work with packs

gold pack

gold pack name folder [lang=] [main=] [test=] [skip=]

Indexes every top-level function, type and global in a Helium folder into packs/name, so Gold can find and call them. See Packs.

OptionMeaning
lang=The product's Helium flavor.
main=The product's root file, used to check new code in place.
test=The command gold test runs.
skip=A regular expression of files to leave out.

gold packs

gold packs

Lists each pack with its language, symbol count and folder.

gold find

gold find pack,pack words to look up

Shows which functions a sentence would retrieve. Use it to check that a paragraph points Gold at the code you meant.

Environment variables

Environment variables change which models Gold uses and where it finds its tools.

Models

VariableDefaultMeaning
GOLD_MODELsonnetThe model that translates and repairs. granite or local:<name> uses the local llama-server.
GOLD_MODEL_HARDopusThe model used for the last repair.
GOLD_MODEL_PORTopusThe model used by gold port.
GOLD_MODEL_FALLBACKsonnetThe model that takes over after the local model's repair rounds.
GOLD_TRIES4How many repair rounds to try. The limit extends up to 10 while each round changes the errors.
GOLD_K70An integer setting read at startup.

Local model

VariableDefaultMeaning
GOLD_LOCAL_URLhttp://127.0.0.1:18790The address of the local llama-server.
GOLD_LOCAL_UNITamni-bonsai.serviceThe unit used to start the local server.
GOLD_LOCAL_WAIT120Seconds to wait for the GPU.
GOLD_LOCAL_ROUNDS2How many repair rounds the local model gets before GOLD_MODEL_FALLBACK takes over.

If the local model is unavailable, the whole build falls back to GOLD_MODEL_FALLBACK.

Paths and tools

VariableDefaultMeaning
GOLD_CACHE~/.cache/goldThe cache folder.
GOLD_ROOTThe installed resource folder if it contains packs, otherwise ~/ai/amni-lang/goldThe Gold root folder.
GOLD_HELIUM~/ai/amni-lang/heliumThe Helium folder.
GOLD_HC$GOLD_HELIUM/build/hcThe Helium compiler.
GOLD_HC_LIB$GOLD_HELIUM/hc/libThe compiler's library folder.
GOLD_VERBOSEunsetSet to any non-empty value for verbose output.
GOLD_LINTunsetSet to warn to build paragraphs that still read as code.
