Dialects

When you port code, a dialect header line brings in the source language's rules: how it sums floats, prints numbers, rounds and casts. Every paragraph follows them, so you never have to restate them.

use os, math
dialect js

Rust

The original is Rust. Unless a block says otherwise:

  • Numbers are f64 (real) and i64/usize (int). x as i64/as u32 from a float truncates toward zero and saturates (NaN -> 0): write sat_int(x) style code with explicit clamps, never a checked as.
  • Float sums with .iter().sum() start at -0.0, so an empty sum is -0.0. f64::abs is fabs. powi(n) is powi(x, n), powf is pow, x.max(y)/x.min(y) are max/min (NaN-ignoring: if one side is NaN return the other).
  • Keep the source's arithmetic grouping exactly; floats are not reassociated.
  • JSON in and out is serde_json: read with json (missing optional fields are absent, null counts as absent), write numbers with json::format_number (serde's shortest round-trip form: 1.0, 1e16, -0.0, NaN/inf as null), keys in struct field order, Option fields that are None are written as null unless the block says they are skipped.
  • {} in format strings is Rust Display for f64: shortest round-trip digits, no exponent, .0 dropped (1, 0.1, 1e-7 prints 0.0000001); {:.N} rounds half to even on the binary value like format_flt(out, v, N).
  • Errors are returned as Err(String); a solver that fails returns a JSON object {"error": "<text>"} with the exact text.
  • Vec<T> is T[>..], &str/String fields are byte[], HashMap iteration order is never relied on.

Python

The original is Python 3. Unless a block says otherwise:

  • int is int, float is real. / is truediv, // and % round down (floor_div, pydivmod), round() is half-to-even (pyround).
  • str(x) is pyfmt(x) (floats print shortest round-trip with .0, 1e-05, inf, nan, True/False), repr(s) is pyrepr(s).
  • Truthiness: empty string, empty list, 0, 0.0 and None are false (truthy).
  • s.lower()/upper()/strip()/split() work on ASCII here; split() with no argument splits on runs of whitespace and drops empty parts; split(sep) keeps empty parts.
  • json.dumps default separators are ", " and ": ", ensure_ascii escapes non-ASCII as \uXXXX, keys keep insertion order; json.loads gives dicts, lists, str, int, float, bool, None.
  • re patterns are used verbatim with Helium regex (search = first match anywhere, match = anchored at start, fullmatch = whole string; re.I = case-insensitive).
  • dict iteration is insertion order; sorted is stable; min/max return the first of equal items.
  • Exceptions caught by the source become explicit error results with the exact message text the source prints.

JavaScript

The original is JavaScript. Unless a block says otherwise:

  • Every number is a double (real); integers stay exact below 2^53. Math.round rounds half up (toward +inf): floor(x + 0.5). toFixed(n) rounds half away from zero on the decimal digits: format_flt(out, v, n, away = true). parseFloat reads the longest numeric prefix, Number("") is 0, Number("x") is NaN.
  • String(x) / template ${x} of a number: shortest round-trip digits, no .0 for integers, exponent form 1e+21 from 1e21 up and 1e-7 below 1e-6, -0 prints 0, NaN, Infinity.
  • || returns the first truthy operand (0, "", NaN, null, undefined are falsy); ?? only skips null/undefined.
  • String methods are UTF-16 but inputs here are ASCII: slice, padStart, toUpperCase, trim as usual; regex literals are used verbatim with Helium regex.
  • Objects keep insertion order for string keys.

Java

The original is Java. Unless a block says otherwise:

  • double is real, int/long are int (but int arithmetic wraps at 32 bits where the source relies on it: say so), (int) x from a double truncates toward zero and saturates, NaN -> 0.
  • Math.abs is fabs, Math.exp/log/sqrt/atan2/hypot keep their names, Math.round is floor(x + 0.5) as an int, Math.max/min with NaN return NaN.
  • Double.toString: shortest digits that round-trip, always with a ., exponent form 1.0E10 from 1e7 up and below 1e-3.
  • String.format("%.Nf") rounds half up on the decimal digits: format_flt(out, v, N, away = true).
  • char is a UTF-16 unit; inputs here are ASCII, so Character.isLetter/toLowerCase are the ASCII versions.
  • ArrayList/arrays are T[>..]; HashMap order is never relied on; Arrays.sort on objects is stable.

Kotlin

The original is Kotlin (JVM). Unless a block says otherwise:

  • Double is real, Int/Long are int; toInt() from a Double truncates toward zero and saturates, NaN -> 0.
  • Regex patterns are used verbatim with Helium regex (find = first match anywhere, matches = whole string, containsMatchIn = any match; RegexOption.IGNORE_CASE = case-insensitive).
  • toDoubleOrNull/toIntOrNull return absent on anything that is not a full valid number (no surrounding spaces).
  • String.format("%.2f") rounds half up on the decimal digits: format_flt(out, v, 2, away = true); Double.toString is Java's (shortest digits, always a ., 1.0E10 from 1e7 up and below 1e-3).
  • ?./?: chains become explicit has-value checks; data classes print as Name(a=1, b=x) only where the source prints them.
  • trim(), lowercase(), split() on ASCII text; split(",") keeps empty parts.

NumPy

The original is Python with numpy. Unless a block says otherwise:

  • np.uint8/uint32/uint64 arithmetic wraps; write it with Helium u8/u32/u64 (wrapping), not int.
  • Vectorized expressions over arrays become plain loops over byte[]/u32[] slices in the same element order; broadcasting a scalar means using it for every element.
  • np.roll(a, k) moves element i to (i + k) mod n; a[::-1] reverses; np.bitwise_xor, &, |, <<, >> act per element with the dtype's width.
  • int.from_bytes(b, "little") / .to_bytes(n, "little") are little-endian loads and stores (load_u64le/store_u64le for 8 bytes).
  • Keep table lookups as tables (precomputed once into a module var), not recomputed per block.
