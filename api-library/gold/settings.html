Settings

Gold reads these environment variables.

VariableDefaultMeaning
GOLD_HELIUM~/ai/amni-lang/helium-goldWhich Helium checkout to check against.
GOLD_HCbuild/hc in GOLD_HELIUMThe Helium compiler to use.
GOLD_HC_LIBhc/lib in GOLD_HELIUMThe Helium library folder to use.
GOLD_ROOTThe resource folder, if it has a packs folder; otherwise ~/ai/amni-lang/goldWhere Gold's files are found.
GOLD_MODELsonnetThe model that writes the Helium. granite or local:<name> uses a local llama-server instead.
GOLD_MODEL_HARDopusThe model for the last repair round.
GOLD_MODEL_PORTopusThe model that writes Gold from existing code.
GOLD_MODEL_FALLBACKsonnetTakes over from a local model after its repair rounds, or when it is unavailable.
GOLD_LOCAL_URLhttp://127.0.0.1:18790Where the local llama-server listens.
GOLD_LOCAL_UNITamni-bonsai.serviceThe service that starts the local llama-server.
GOLD_LOCAL_WAIT120Seconds to wait for the GPU before using the local model.
GOLD_LOCAL_ROUNDS2How many repair rounds the local model gets.
GOLD_TRIES4Repair rounds. This extends up to 10 while each round changes the errors.
GOLD_K70How many product functions the model sees per build.
GOLD_CACHE~/.cache/goldThe cache folder.
GOLD_VERBOSEOffPrint each step. Set it to any non-empty value to turn it on.
