gfx/sparks

Fast GPU particles drawn as glowing camera-facing discs in the gfx.scene3d color pass.

import gfx.sparks; · sparks:: · 7 functions, 3 types, 11 constants · Source

Notes from the source
sparks: GPU particles. Emission writes slots of a fixed ring on the CPU side;
each step a compute shader integrates every live particle in place, and the
colour pass of gfx.scene3d draws them as additive camera-facing discs.
