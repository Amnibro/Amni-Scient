gfx/codec_jpeg

Decode baseline JPEG files to RGBA pixels.

import gfx.codec_jpeg; · codec_jpeg:: · 7 functions, 2 types, 3 constants · Source

Notes from the source
codec_jpeg: baseline and progressive JPEG decoding to RGBA8 (ITU-T T.81, JFIF color).
Huffman-coded 8-bit DCT with any sampling factors and restart intervals; grayscale or YCbCr.
Arithmetic-coded, lossless and CMYK files are reported as not decodable.
