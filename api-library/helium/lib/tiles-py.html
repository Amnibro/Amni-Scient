Converts a JSON node to an integer, handling booleans, numbers and numeric strings, returning false if impossible.

`int_of(text)` is Python's int() of a str. It returns the int and true, or 0 and false where Python raises ValueError. After stripping whitespace the text is an optional + or - and then ASCII digits, where a single underscore may sit between two digits; leading zeros are fine. A number that does not fit in a signed 64-bit int also gives 0 and false.

str_of function

Returns a JSON node as a string, using the raw text for strings and Python repr otherwise.

`str_of(d, node)` is Python's str() of a JSON value: None, True, False, a number like `pyfmt`, a str unchanged, and a list or object as Python's repr, `[a, b]` and `{'key': value}` with ", " between items and ": " after keys, strings inside written by `pyrepr`, nested values the same way.
