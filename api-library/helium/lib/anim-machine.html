anim/machine

The animation state machine: states, conditional transitions, crossfades, phase sync and interruption.

import anim.machine; · anim:: · 13 functions, 6 types, 9 constants · Source

Notes from the source
anim/machine: motions (a clip or a blend space) and the animation state
machine: states, transitions with conditions / exit times, smoothstep
crossfades, phase sync, and interruption by freezing the last output pose.
Root motion flows through: every motion reports its root displacement
for the tick and the machine blends them with the same weights as the
poses. Clean-room; see DESIGN.md.

}

Machine type

struct Machine {
	cur i32, phase f32, time_in f32,
	src_kind i32,          // 0 none, 1 a live state, 2 a frozen pose
	src i32, src_phase f32,
	fade f32, fade_dur f32,
	params f32[16],
	root float3,           // root displacement of the last tick (character space)
	root_v float3,         // its velocity (m/s); a frozen source keeps moving at it
	frozen_v float3,
	fired i32,             // transition index fired this tick, or -1
	ticks i32,
	// frozen source of an interrupted fade: the last output pose, carried
	// forward by its last per-tick joint change (frozen_d) with that change
	// decaying linearly to zero over the first 30% of the fade, so joint
	// velocity stays continuous at the interrupt instead of dropping to zero,
	// while the extrapolated pose does not drift far from what was on screen.
	frozen Pose, frozen_d Pose, last Pose, prev Pose,
}

Runtime state of a machine, including current state, phase, fade, parameters, root motion and frozen pose for interruptions.
