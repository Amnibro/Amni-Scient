gfx/zlib

Decompress DEFLATE and zlib streams, the compression used inside PNG files.

import gfx.zlib; · zlib:: · 5 functions, 1 types, 6 constants · Source

Notes from the source
zlib: a DEFLATE decoder (RFC 1951) with the zlib wrapper (RFC 1950), for PNG image data.
Huffman codes are canonical; each table keeps a 9-bit direct lookup and walks the
per-length counts for longer codes.
