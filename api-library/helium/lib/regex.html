regex

Regular expressions over bytes. Matching time grows linearly with the text, so a bad pattern cannot hang a program.

import regex; · regex:: · 39 functions, 7 types, 17 constants · Source

Notes from the source
regex: byte-oriented regular expressions.
A pattern is parsed into a tree, the tree is laid out as a list of
instructions, and a Pike machine runs every live thread in lockstep over
the text, so time is linear in the text. Threads keep a priority order, so
the match chosen is the leftmost one and, among those, the one a
backtracking matcher would find first.

syntax: literals, ., [...] and [^...] with ranges, \d \w \s \D \W \S,
\n \t \r \f \v \xHH, groups (...) and (?:...), |, * + ? {m} {m,} {m,n}
(a trailing ? makes them lazy), ^ and $ for the ends of the text, \b \B.
