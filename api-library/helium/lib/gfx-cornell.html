gfx/cornell

The classic Cornell box test scene as plain triangle data.

import gfx.cornell; · cornell:: · 9 functions, 0 types, 15 constants · Source

Notes from the source
cornell: the Cornell box scene shared by the CPU path-traced reference
(hc/test/gfx/gi/cornell_pt.amni) and the renderer's GI gate in gfx_smoke, so both
see the same triangles. Geometry from the Cornell Box Data published by the Cornell
University Program of Computer Graphics (millimetres, scaled by SCALE to scene
units): the room's walls axis-aligned to 556 x 548.8 x 559.2, the short and tall
blocks from their published top-face corners extruded to the floor. Pure data, no
gfx imports.
