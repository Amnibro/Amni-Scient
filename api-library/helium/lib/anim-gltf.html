anim/gltf

Read skinned characters from .glb files: skeletons, inverse bind matrices and animation samplers.

import anim.gltf; · anim:: · 24 functions, 3 types, 6 constants · Source

Notes from the source
anim/gltf: a clean-room GLB (glTF 2.0 binary) reader for skinned
characters, written from the Khronos glTF 2.0 specification: the 12-byte
header and JSON/BIN chunks, accessors over buffer views (float and
normalized integer components), node TRS, skins with inverse bind
matrices, and animation samplers (LINEAR, STEP, CUBICSPLINE), resampled
into the clip bank at a uniform rate. Sparse accessors and external
buffers are not supported (GLB with one embedded BIN chunk only).

Loads every animation into the clip bank, resampled at `fps` (or the clip's extras.fps when fps <= 0, default 30). Clip names get `prefix`. Every clip's root motion is set on the joint named `root_name` (if any). Returns the number of clips loaded.
