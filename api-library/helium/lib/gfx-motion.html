gfx/motion

Pose glTF scenes: sample animation channels, walk the node tree, and build joint matrices and morph weights.

import gfx.motion; · motion:: · 10 functions, 0 types, 6 constants · Source

Notes from the source
motion: poses for glTF scenes. Samples animation channels (step, linear and
cubic Hermite spline per the glTF 2.0 specification), walks the node hierarchy
into world matrices, and builds joint matrices and morph weights for drawing.
The pose arrays are indexed like gltf::nodes.
