gfx/codec_png

Decode PNG files to RGBA pixels and write 8-bit PNG files.

import gfx.codec_png; · codec_png:: · 12 functions, 0 types, 2 constants · Source

Notes from the source
codec_png: PNG decoding to 8-bit RGBA (PNG specification, ISO/IEC 15948).
Handles every color type and bit bit_depth, palettes with tRNS, and Adam7 interlacing.
16-bit samples keep their high byte. encode/write produce 8-bit PNGs with stored (uncompressed) deflate blocks.
