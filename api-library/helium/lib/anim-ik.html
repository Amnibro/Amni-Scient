anim/ik

Two-bone and FABRIK chain inverse kinematics, plus a foot-planting helper.

import anim.ik; · anim:: · 11 functions, 3 types, 1 constants · Source

Notes from the source
anim/ik: analytic two-bone IK (law of cosines, pole vector), FABRIK chain
IK (Aristidou & Lasenby 2011, "FABRIK: A fast, iterative solver for the
Inverse Kinematics problem", Graphical Models 73(5)), and a foot-planting
helper (ground following, contact locking, pelvis drop). All solvers work
in character (model) space on a pose plus its FK result, and write local
rotations back into the pose; call fk() again afterwards. Clean-room.

two_bone_ik function

two_bone_ik(sk Skeleton&, p Pose&, m Model&, a i32, b i32, c i32, target float3, pole float3, weight f32, keep_end bool) f32

Solves two-bone IK on a joint chain toward a target and pole, returning the remaining distance.

Two-bone IK on the chain a -> b -> c (b's parent must be a, c's parent b). target: where c should go; pole: a point the middle joint should bend toward; weight blends the result; keep_end keeps c's model orientation. Returns the remaining distance |c - target| after solving (0 if reached).

soft_reach function

soft_reach(d f32, reach f32) f32

Returns a distance smoothly compressed so it stays below the limb's full reach.

Soft reach map, fixed per limb: d <= s = SOFT_K*reach is unchanged; above it d' = s + w*tanh((d - s)/w), w = reach - s. tanh has slope 1 and curvature 0 at 0, so the map is C2 at s, monotone, and always < reach.
