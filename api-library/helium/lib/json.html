format_number function

inline format_number(out byte[>..]&, v real, plus_exp bool = false)

Appends a real number to the output buffer as JSON text, writing "null" for NaN or infinity and ".0" on whole values; plus_exp adds a "+" to positive exponents.

a finite number in its shortest exact form: plain decimals for 1e-5 up to 1e16, with ".0" on whole values, and d.ddde<n> outside that range (d.ddde+<n> for positive n with plus_exp, as serde_json writes it). JSON has no NaN or infinity, so those come out as null
