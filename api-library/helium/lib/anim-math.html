anim/math

Quaternions and rigid transforms for the animation runtime.

import anim.math; · anim:: · 25 functions, 2 types, 4 constants · Source

Notes from the source
anim/math: quaternions and rigid transforms for the animation runtime.
Clean-room: written from the textbook definitions (Hamilton product,
q v q*, nlerp/slerp as in Shoemake 1985 "Animating rotation with
quaternion curves"), not from any engine. Quaternions are float4
{x, y, z, w} with w the scalar part; all rotations are unit quaternions.
