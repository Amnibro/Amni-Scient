anim/skin

Skinning palettes and linear-blend skinning of glTF mesh data on the CPU.

import anim.skin; · anim:: · 6 functions, 2 types, 5 constants · Source

Notes from the source
anim/skin: skinning palettes (model * inverse bind, as column-major 4x4)
and linear-blend CPU skinning of a glTF mesh primitive. On the GPU the
palette is what gets uploaded; the CPU path is for tests, tools and the
software renderer. Clean-room; see DESIGN.md.

skin_cpu function

skin_cpu(mesh SkinMesh, pal Palette&, out_p float3[>..]&, out_n float3[>..]&, out_t float4[>..]&)

Skins every vertex of a mesh on the CPU with linear blending, writing positions, normals and tangents to the output arrays.

Linear blend skinning of every vertex. The weighted 3x4 matrix A = sum_k w_k M_k is formed once per vertex (same arithmetic as skin.comp), then: p' = A p t' = normalize(A3 t.xyz), w' = w * sign(det A3) n' = normalize(cof(A3) n * sign(det A3)) where A3 is the upper 3x3 and cof(A3) = det(A3) * inverse-transpose(A3):
