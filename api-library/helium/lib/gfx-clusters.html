gfx/clusters

Assigns scene lights to a 3D grid of view-frustum cells so renderers can efficiently shade many lights per pixel.

build function

build(view gfx::mat4, tan_x f32, tan_y f32, near f32, far f32, lights const float4[:], out u32[>..]&)

Builds the cluster light grid from view-space lights, writing cell headers followed by light index lists into out.

`build(view gfx::mat4, tan_x f32, tan_y f32, near f32, far f32, lights const float4[:], out u32[>..]&)` fills `out` from scratch. `lights[i]` holds a world position in x, y, z and the range in w. The grid has `CX * CY * CZ` cells; a cell's index is `(z * CY + y) * CX + x`, where x runs left to right across the screen, y top to bottom, and z through exponential depth slices: slice k covers view dep
