gfx/sdf_font

A built-in font drawn from vector strokes, so text stays sharp at any size with no font files.

import gfx.sdf_font; · 15 functions, 3 types, 19 constants · Source

Notes from the source
sdf_font: an original procedural signed-distance-field font. ASCII 32..126
are vector strokes (line segments and circular arcs) defined in code; there
are no font files. sdf_bake renders a 1024x512 distance atlas on the CPU in
two weights (stroke radius 1.3 and 2.1 cell px); sdf_init uploads it.

Text is emitted as TextVtx quads (pos, uv, col; 20 bytes). Draw them with
shaders/sdf_text.vert and shaders/sdf_text.frag, with sdf_texture() and
sdf_sampler() bound at fragment sampler slot 0. In the vertex stream:
  uv.x <  0   flat colour (solid rects can share the pipeline)
  uv.x >= 2   outline pass (uv.x - 2 is the atlas coordinate)
  otherwise   glyph fill
sdf_text(vs, x, y, px, text, colour, weight, outline): px is the cap height
in pixels and (x, y) the top-left of the cap box; weight 0 regular, 1 bold;
outline false adds a soft drop shadow, true a dark outline.
sdf_text_w(text, px) is the advance width in pixels.
