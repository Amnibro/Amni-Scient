level_size function

level_size(kind int, w int, h int, n int) int

Returns the uncompressed byte size of mip level n for the given format kind and base dimensions.

`level_size(kind int, w int, h int, n int) int` is the byte count of mip level n of a w by h picture: the level is `max(w >> n, 1)` by `max(h >> n, 1)`; kind 0 takes 4 bytes per pixel; the others are what the bc module's own `size` function gives for that level, called as bc::size(kind, level width, level height) (the module imports gfx.bc; no local copy of that function).

span function

span(file const byte[:], info Info, n int) int, int

Returns the byte offset and stored length of mip level n, or -1 and 0 when invalid.

`span(file, info Info, n int) int, int` (file: read-only byte slice, which may be only the start of the file) returns two ints, the byte offset and the stored byte length of level n, read from the level index in `file`. It returns -1 and 0 when `info.ok` is false, n is outside 0 to levels - 1, or `file` is shorter than 80 + 24 * (n + 1) bytes.

read function

read(file const byte[:]) Info

Parses and validates a KTX2 file header and level index, returning an Info with ok false and an error code on failure.

`read(file) Info` (file: read-only byte slice holding the whole file) is `head(file)` plus one more check when that is ok: for every level, the offset and length from `span` must not pass the end of the file (offset plus length at most the file length), else the result has `ok` false and error E_LEVEL. No header parsing here: `head` does it all.

level function

level(file const byte[:], info Info, n int, out byte[>..]&) bool

Extracts mip level n into the output buffer, inflating zlib data and verifying it; returns false on failure.

`level(file, info Info, n int, out) bool` (file: read-only byte slice holding the whole file; out: growable byte array by reference) clears `out`, takes level n's offset and length from `span`, and is false when the offset is negative or offset plus length passes the end of the file; otherwise it is the result of `unpack` on that part of the file.
