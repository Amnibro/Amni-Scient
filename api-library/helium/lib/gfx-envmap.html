gfx/envmap

Lets a program load environment maps and prefilter them into GGX-blurred cubemaps for image-based lighting, including sun and haze effects.

load function

load(path const byte[:]) bool

Loads an HDR image file as the environment map, returning false if reading or decoding fails.

`load(path const byte[:]) bool` reads the file with `read_file` into a local byte array (false on failure), decodes with `codec_hdr::decode` into a local f32 array (false when not ok), calls `set_equirect` and returns true.
