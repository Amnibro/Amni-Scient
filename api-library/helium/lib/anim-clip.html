Clip Bank 11

Clip type

struct Clip {
	name byte[..64],
	nj i32, frames i32, fps f32, dur f32, base int,
	looping bool, additive bool,
	root i32,          // root-motion joint, -1 for none
	root_v float3,     // average root velocity over one period (m/s)
	root_end float3,   // root translation delta over one period
	speed f32,         // horizontal root speed (m/s)
}

Describes one animation clip's metadata, including frame count, rate, looping, additive flag, and root-motion data.

Frame-major storage: key (f, j) of clip c is at CLIPS[c].base + f * nj + j. A looping clip's last frame is expected to equal its first, so its period is dur = (frames - 1) / fps.

Root Motion 4

clip_set_root function

clip_set_root(c int, root i32)

Sets a clip's root-motion joint, or none if negative, and computes its average horizontal velocity and speed.

Root motion. The root joint's horizontal (XZ) translation is the motion; the in-place pose pins it to its frame-0 value. Yaw is left in the pose (none of the target rigs turn through their loco clips).
