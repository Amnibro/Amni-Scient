Ipio2Row type

struct Ipio2Row { v int }

Row type holding one 24-bit chunk of the table of 2/pi bits used for argument reduction.

struct `Ipio2Row` with one field `v int`. It holds one row of the 2/pi bit table. Each row is 24 bits of 2/pi: row i is the bits from 24*i to 24*i+23 after the binary point.

ipio2_table function

ipio2_table() Ipio2Row[66]

Returns the 66-entry table of 2/pi bit chunks used by large-argument reduction.

The table above is the source's 66-entry variant. f32 inputs never index past entry 23 (jv <= 4 and jz < 20), so the source's 690-entry table gives identical results. Module-level `var IPIO2` holds `ipio2_table()`. It is filled once, on first use, and kept.

scalbn function

scalbn(x real, n int) real

Returns x multiplied by 2 raised to the power n, built from exponent bits.

`scalbn(x real, n int) real` returns x times 2^n. It multiplies x by the double whose bits are (0x3ff+n)<<52. This is exact here, because every caller keeps n inside the normal exponent range.
