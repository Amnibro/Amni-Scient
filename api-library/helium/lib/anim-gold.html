anim/gold

A ready-made walking and running character: speed blending, action states, an upper-body layer, root motion and foot planting.

import anim.gold; · anim:: · 9 functions, 2 types, 8 constants · Source

Notes from the source
anim/gold: the "gold angle" locomotion character used by the tests and
the JK / BFME proofs: "blend walk into run above 3 m/s; plant feet".
A 1D speed space (idle, walk at its natural speed and stretched to
2.6 m/s, run from 3.4 m/s at a slowed cadence up to 6 m/s, all rate
matched), an action state and an interrupting action state, an additive
upper-body layer, root motion into a world transform, and two-leg foot
planting on gently rolling ground.

WALK_TOP constant

let WALK_TOP = 1.8;    // walk stretched up to here

Speed in meters per second up to which the walk clip is stretched before blending toward run.

The walk->run blend band [WALK_TOP, RUN_LOW] is centred on 3 m/s and 2.4 m/s wide: the speed spring crosses it in about 0.3 s when braking from a run (a 0.8 m/s band took ~0.1 s, a near-miss crossfade the pop test flags, which is what capped the spring at 2.4 s).

hc/lib/anim/gold.amni:28

SPEED_W constant

let SPEED_W = 5.27

Natural frequency in radians per second of the critically damped spring that smooths the speed command.

Speed command smoothing: a critically damped spring (natural frequency SPEED_W rad/s), so the speed parameter is C1 in time. The previous linear slew (8 m/s^2) started and stopped its acceleration instantly, and the walk/run blend it drives turned that into a per-frame velocity kink on the whole body (seen by the per-state pop thresholds, see DESIGN.md).

spring_cd function

spring_cd(x f32&, v f32&, target f32, w f32, dt f32)

Advances a critically damped spring one step, updating position and velocity toward a target over dt seconds.

Exact step of x'' = w^2 (target - x) - 2 w x' (critical damping, the closed-form solution x = target + (c1 + c2 t) e^(-w t)).
