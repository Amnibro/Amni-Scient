decode function

decode(b const byte[:], out f32[>..]&) int, int, bool

Decodes Radiance HDR bytes into RGBA float pixels, returning width, height and false on malformed or unsupported data.

`decode(b const byte[:], out f32[>..]&) int, int, bool` returns width, height, ok and fills `out` (cleared first) with 4 floats per pixel in file order (red, green, blue, 1.0), top row first. The text header ends at the first empty line; a `FORMAT=` line other than `32-bit_rle_rgbe` is a failure. The next line must be `-Y <height> +X <width>` with both positive and at most 32768, otherwise failure
