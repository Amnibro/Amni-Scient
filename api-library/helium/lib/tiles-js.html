to_fixed function

to_fixed(x real, digits int) byte[>..]

Formats a real number with a fixed count of decimal digits, returning "NaN" for NaN and exponent-style output at 1e21 or above.

`to_fixed(x, digits)` is JavaScript's x.toFixed(digits) for digits from 0 to 100: "NaN" for NaN, `num_str(x)` when the size of x is at least 1e21, and otherwise the exact value of x rounded to that many decimals, a tie going away from zero, written as `math::fabs` of x with exactly that many decimals and a minus sign in front when x is below zero, so -0.001 with 2 decimals is "-0.00" and -0 is "0.
