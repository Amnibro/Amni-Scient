dictionary

A hash map from any key type to any value type, with insert, lookup, update, remove and iteration.

import dictionary; · 30 functions, 2 types, 0 constants · Source

Notes from the source
dictionary: a hash map from K to V.
Open addressing with linear probing over a power-of-two table, kept as three
parallel arrays (keys, vals, states) so a probe walks the one-byte states and
only touches a key on a live slot. A slot's state is 0 (never used),
1 (holds an entry) or 2 (entry removed). The table grows when live plus
removed slots would pass three quarters of it, so a probe always meets a
never-used slot.
