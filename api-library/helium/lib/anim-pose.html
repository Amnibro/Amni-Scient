Accum type

struct Accum { n i32, wsum f32, t float3[128], r float4[128], s float3[128] }

Accumulator that sums weighted poses so several sources can be blended and then normalized.

N-way normalized weighted blend, done as an accumulator so callers can sample each source straight into it. Rotations are summed with their sign aligned to the first contribution, then normalized (the normalized weighted quaternion average; exact for n = 2 up to nlerp's arc spacing).
