each_sum function

each_sum<T, F>(out T[:], m int)

Fills each output element with the sum of the block's values over m columns, matching a nested loop exactly.

each_sum: out[i] = F(i, 0) + F(i, 1) + ... + F(i, m - 1), added from zero in j order, so it is bit-identical to the nested loop even for reals. The rows run eight at a time, each with its own sum, so the eight additions in flight are independent.
