gf

Fast GF(2^8) arithmetic over byte buffers and the AES S-box and MixColumns steps, using CPU vector instructions when present.

import gf; · gf:: · 10 functions, 0 types, 5 constants · Source

Notes from the source
gf: arithmetic in GF(2^8) with the AES polynomial (x^8 + x^4 + x^3 + x + 1)
over whole byte buffers, plus the AES S-box and MixColumns step. Uses the
CPU's GFNI and VAES instructions when it has them.

dot64 function

inline dot64(out byte[:], at int, vecs const byte[:], vat int, s const byte[:], sat int, rot int = 0, orot int = -1)

Computes one 64-byte block as the XOR of sixteen 64-byte vectors multiplied by repeated 4-byte groups, optionally rotating the stored result.

out[at..at+64] = XOR over j < 16 of vecs[vat+64j .. +64] times, byte by byte, the 4-byte group s[sat + 4*((j+rot)%16) ..] repeated across the 64 bytes. With orot from 0 to 15 the result is turned up by that many 4-byte groups before it is stored: result byte k lands at out[at + (k + 4*orot) % 64]. out must not overlap vecs or s

sixteen dot64 products at once over whole 1024-byte blocks: row y of out is the dot64 of vecs with row y of s, a row being 64 bytes
