gfx/obj

Loads Wavefront OBJ model files, parsing vertices, named groups, and faces into triangle lists for rendering.

V constant

var V f32[>..]

Holds the flat list of vertex coordinates (x, y, z triplets) from the most recently loaded OBJ file.

Imports: os. Namespace obj. Reads Wavefront OBJ meshes with named groups, with no dependency on the renderer. Module vars: `V` (f32, three per vertex), `names` (a list of group names in order of appearance, each a growable byte array) and `tris` (int, four per triangle: the group's index in `names`, then three vertex numbers counting from 0).

load function

load(path const byte[:]) bool

Loads an OBJ file, replacing current data, and returns false if the file cannot be read.

`load(path) bool` clears the module vars and reads the file. A line starting with "v " adds its first three numbers to `V`. A line starting with "g " makes its name (the text after "g " up to the end of the line, without trailing spaces or a carriage return) the current group, adding it to `names` when new. A line starting with "f " lists three or more corners, each a vertex number counting from 1

tris_of function

tris_of(name const byte[:], out int[>..]&)

Fills the output array with vertex indices, three per triangle, for the named group; empty if unknown.

`group(name) int` is the index of the name in `names`, or -1. `tris_of(name, out)` clears out (a growable int array) and fills it with the three vertex numbers of every triangle of that group. `centroid(name) real, real, real` is the mean position of the distinct vertices used by that group's triangles, or 0, 0, 0 when the group has none.

normals function

normals(idx const int[:], out f32[>..]&)

Computes per-vertex normals for the given triangle vertex indices into the output array, skipping triangles with out-of-range indices.

`normals(idx, out)` (idx: read-only int slice of triangles) clears out (growable f32) and fills it with three numbers per vertex of `V`: each vertex's sum of the cross products of the edges (b minus a) and (c minus a) of the triangles that use it, scaled to length one (0, 1, 0 when shorter than 1e-20).
