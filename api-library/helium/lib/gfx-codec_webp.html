gfx/codec_webp

Decodes WebP image files, both lossy and lossless, into pixel data with optional alpha transparency for use in programs.

Error Reporting 1

error function

error() const byte[:]

Returns the message describing the most recent decoding failure.

Namespace codec_webp. Decodes WebP still pictures to RGBA8 (4 bytes per pixel, top row first): lossy VP8 with or without an ALPH alpha chunk, lossless VP8L, in the simple and the extended (VP8X) RIFF container. The result matches libwebp's `WebPDecodeRGBA` byte for byte: colors are not premultiplied and alpha is 255 when the file has none. Nothing here may crash, loop forever or read past the end

Returns whether the bytes begin with a RIFF container carrying the WebP signature.

`is_webp(b)` gives whether b is at least 12 bytes with "RIFF" at 0 and "WEBP" at 8. `size(b)` copies b to src and runs `parse`, giving width, height and the result. `decode(data, px)` empties px, copies data to src, parses, and runs `vp8l` or `vp8`; on success px holds width times height times 4 bytes and it gives width, height, true; on failure px is emptied and it gives 0, 0, false.
