fixed function

fixed(out byte[>..]&, x real, decimals int)

Appends a real formatted with a fixed number of decimal places, writing NaN or inf for non-finite values.

`fixed(out, x, decimals)` appends Rust's `{:.N}` of x with N decimals: "NaN", "inf" or "-inf" for those values, and otherwise std's `format_flt(out, x, decimals)`, which rounds the exact value half to even and writes a minus sign whenever the sign bit is set, so -0.0 and -0.001 at two decimals both print "-0.00".

POW10 constant

var POW10 real[..309]

Lookup table of powers of ten from 1e0 to 1e308, filled lazily for number parsing.

`POW10` is a global table of 309 reals where entry k is the double nearest 10 to the power k, filled once by `pow10_init()`: for each k, the first result of std's `parse_flt` (which returns a real and a bool) of the text "1e" followed by the decimal digits of k. The table is reserved for 309 entries before it is filled.
