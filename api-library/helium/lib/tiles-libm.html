Scaling 1

scalbn function

scalbn(x real, n int) real

Returns x multiplied by 2 raised to the integer n, clamping extreme exponents.

`scalbn(x, n)` with n a 32-bit int. If n is above 1023, multiply x by 2^1023 and subtract 1023. If n is still above 1023, do it again, then clamp n to 1023. Else if n is below -1022, multiply x by (2^-1022 * 2^53) and add 969. If n is still below -1022, do it again, then clamp n to -1022. The result is x times the float whose bits are (0x3ff + n) shifted left 52.
