anim/gpuskin

Linear-blend skinning on the GPU through a self-contained Vulkan compute backend.

import anim.gpuskin; · gsk:: · 25 functions, 1 types, 32 constants · Source

Notes from the source
anim/gpuskin: GPU linear-blend skinning on a self-contained Vulkan compute
backend (own FFI, own buffer layout, own shader: anim/skin.comp compiled by
Helium's GLSL->SPIR-V compiler `hcn --spv`). Clean-room: written from the
Vulkan 1.0 spec struct layouts and the LBS formula v' = sum_k w_k M_k v
(Magnenat-Thalmann et al. 1988); see DESIGN.md. Does not use hc/lib/gfx.

Buffer layout (the adapter contract; any renderer can bind these):
  rest   vec4[3*nv]   (pos.xyz,1) (normal.xyz,0) (tangent.xyz,w)  device-local
  wts    vec4[nv]     4 weights, normalized                device-local
  jts    uint[nv]     4 joint indices, 8 bits each         device-local
  pal    vec4[3*nj*nchar] rows of the 3x4 affine palette   host-visible
  par    uint[4]      nv, nj, nchar, 0                     host-visible
  out    vec4[3*nv*nchar] skinned (pos,1)(normal,0)(tangent,w)  device-local, storage+vertex
  (normal and tangent unit length; normal via the inverse-transpose)
Dispatch (ceil(nv/64), nchar, 1). `out` is what a vertex shader reads.
