anim/space

1D and 2D blend spaces that turn values such as speed into weights over sample clips.

import anim.space; · anim:: · 7 functions, 1 types, 2 constants · Source

Notes from the source
anim/space: 1D and 2D blend spaces. A blend space turns one or two
parameters (e.g. speed, or velocity x/z) into weights over sample clips.
 1D: samples sorted on x; piecewise-linear weights between neighbours.
 2D: Delaunay triangulation of the sample points (Bowyer 1981 / Watson
     1981 incremental insertion) and barycentric weights in the containing
     triangle; outside the hull the point is projected onto the nearest
     hull edge. Both are continuous in the parameters, so a smoothly
     changing parameter never makes a weight jump. Clean-room; see DESIGN.md.
