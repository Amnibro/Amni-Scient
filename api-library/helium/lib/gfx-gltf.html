gfx/gltf

Load glTF 2.0 models (.glb and .gltf) into memory pools the renderer uploads in one go.

import gfx.gltf; · gltf:: · 30 functions, 12 types, 47 constants · Source

Notes from the source
gltf: reads glTF 2.0 assets (.glb, and .gltf with external or data-URI buffers)
into flat global pools that the renderer uploads in one go.
Written from the Khronos glTF 2.0 specification. Every index stored in a pool
record is absolute (already offset by the owning asset's base), or -1 for none.
