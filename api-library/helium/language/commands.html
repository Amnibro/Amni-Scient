Commands and options

The compiler is one command, hc. Run hc help to print this list in short form.

hc <command> file [options] [-- program args...]
hc file [options] [-- program args...]

Commands

CommandWhat it does
hc runCompile natively into the cache and run the program. hc file does the same.
hc buildBuild an executable: -o out for native, -o out.c for C, --web for WebAssembly.
hc checkParse and typecheck only.
hc fetchClone the git packages the program declares.
hc lspRun the language server: diagnostics, hover, definition, references, rename, symbols, completion, signature help and inlay hints.
hc versionPrint the version.
hc helpPrint the short help.

Options

OptionMeaning
-o pathOutput path for build. The default is the file's name without its extension.
--debugAdd overflow, range and tag checks that name the source line.
-DNAME=VSet a runtime define.
--offlineFetch no packages. A package missing from the cache is an error.
--include file.hBuild the C that the program's extern functions come from into a shared library with cc.
--cBuild C instead of a native executable.
--webBuild WebAssembly, and write the helium.js host beside it.
--v3Target x86-64-v3 (Haswell and later): AVX2 vector code and three-operand scalar floats.
--v4Target x86-64-v4: --v3 plus AVX-512 integer-lane vector code.
--vhostPick --v4, --v3 or neither from this machine's CPU, like -march=native.
--allWith check: also check every typed function nothing calls.
--updateWith fetch: fetch tags and branches again.

Packages

A program declares a git package right in its import line:

import name from "owner/repo@ref";

hc fetch file clones what a program declares, and a build fetches anything missing unless you pass --offline.

Environment variables

VariableMeaning
HC_LIBThe library folder. By default, lib beside hc, then hc/lib.
HELIUM_HOMEWhere saved lookup tables live, instead of ~/.helium.
HELIUM_GPUoff keeps lookup-table fills on the CPU. discrete prefers the discrete GPU.
HELIUM_GPU_MIN_MSHow long a CPU fill must take before the GPU takes over. The default is 30 ms.
HELIUM_GPU_LOG1 reports what ran where. 2 also writes each table's compute shader.
