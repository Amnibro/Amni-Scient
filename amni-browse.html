AMNI-BROWSE

PRIVACY-FIRST BROWSER • ZERO TELEMETRY • ANDROID + WINDOWS

VIEW ON GITHUB ☕ SUPPORT

A privacy-first browser for Android (v0.16.9 beta). It's private by default with zero telemetry, and you get tabs, collapsible groups and per-tab favicons. There's a Windows desktop build too: v0.13.0 on the Chromium/WebView2 engine. Both download below.

  • Zero telemetry · tracker stripping · private tabs · omnibox
  • Tab groups · tile switcher · bookmark folders · import
  • Android: system WebView, signed APK, sideload · Android 8+
  • Windows: Chromium (WebView2), ad blocker, DoH · Servo engine parked in the source

YOUR BROWSING IS YOURS

I built it around one rule, in Rust on Windows and Kotlin on Android: nothing leaves your machine unless you tell it to.

ZERO TELEMETRY

No analytics, no crash reporting, no phone-home. The only requests it makes are for the pages you open and the search engine you picked.

BUILT-IN AD BLOCKER

On Windows, ad networks, tracking pixels and beacons get blocked on every request. The filter rules ship inside the exe, so there are no external list downloads. Android blocks third-party cookies.

PRIVATE TABS

Private mode keeps history, cookies and cache out of persistent storage. And on Android, 25 tracking parameters (UTM, fbclid, gclid, msclkid and more) get stripped from every link you open.

TAB GROUPS

Name a group, give it a color, and tap its chip to collapse it out of the way. Every tab gets its favicon, and on Windows you can pin the ones you live in.

PASSWORDS, YOUR WAY

On Windows, Chromium's own password autosave and form autofill, with a toggle in Settings, saved in a local data folder. On Android, it hands off to the autofill service your phone already uses.

CLICK-TO-INSTALL

One PowerShell line, irm https://amni-scient.com/browse/install.ps1 | iex, downloads the win64 zip, drops amni-browse.exe in %LOCALAPPDATA%\AmniBrowse, pins it to the Start Menu and Desktop, and registers it as a browser. Run it again any time to update: it checks this site first, then GitHub.

HOW IT WORKS

1. LAUNCH

On Windows, a single Rust exe opens a frameless native window. The chrome (toolbar, URL bar, tab strip) lives in its own WebView2, apart from every page, so no site can tamper with it.

2. RESOLVE

On Android, tracking parameters get scrubbed from a link before it loads. On Windows, switch on DoH and DNS queries go out over HTTPS to the resolver you picked.

3. BLOCK

On Windows, the ad blocker runs at the request layer, not as a content extension. Known ad networks, pixels and beacons are cancelled before they fetch.

4. KEEP LOCAL

Bookmarks, history, sessions: every byte stays on your device. No account, no sync, no backup you didn’t ask for.

SEVEN-PILLAR ARCHITECTURE

Under the hood, the desktop source tree is split into seven isolated pillars. Each one has a single job and talks to the others over an explicit IPC boundary.

PILLARROLE
UIHTML/CSS/JS chrome (webview) or native egui chrome (servo-engine)
CommunicationIPC protocol (70+ message types) + DNS-over-HTTPS resolver
StorageBookmarks, history, sessions, downloads, profiles — local only
EncryptionAES-256-GCM vault, PBKDF2-HMAC-SHA256 KDF, encrypted autofill
PlatformOS windowing: tao+wry or winit+wgpu+egui compositor
EngineTabs, ad blocker, extensions, permissions, devtools, app launcher
MediaGStreamer-backed media path for the parked Servo engine • native WebView2 playback, DRM/MSE sites (Netflix, YouTube, …) included, in the shipped Windows build
