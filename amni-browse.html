AMNI-BROWSE

PRIVACY-FIRST • ZERO TELEMETRY • SINGLE RUST BINARY

VIEW ON GITHUB ☕ SUPPORT

A privacy-first web browser powered by the real Servo engine (v0.12.1). One Windows exe, click-to-install, auto-updates from this site.

  • Real Servo (libservo) is the default · WebView2 only for DRM/MSE
  • Zero telemetry · ad blocker · private tabs · omnibox
  • AES-256-GCM vault + Bitwarden / 1Password / KeePassXC fill
  • One-click install + in-app updates from amni-scient.com / GitHub

YOUR BROWSING IS YOURS

A ground-up web browser built in Rust around one principle — nothing leaves your machine unless you tell it to.

ZERO TELEMETRY

No analytics, no crash reporting, no phone-home. The binary makes network requests only to the pages you navigate to.

BUILT-IN AD BLOCKER

Ad networks, tracking pixels, fingerprinting scripts blocked at the navigation layer. Filter rules bundled in the binary — no external list downloads.

CLICK-TO-INSTALL

One Setup command downloads the win64 zip, drops amni-browse.exe in %LOCALAPPDATA%\AmniBrowse, pins Start Menu + Desktop, and registers as a browser. The app then checks this site (then GitHub) for updates.

BRING YOUR OWN VAULT

Amni vault (AES-256-GCM, PBKDF2 600k) plus Bitwarden CLI, 1Password CLI, and KeePassXC. A key icon on the URL bar fills the login like Chrome. One-match autofill is a toggle. Secrets stay on your machine.

PRIVATE TABS

Private browsing mode keeps history, cookies, and cache out of persistent storage. Tracking parameters (UTM, fbclid, gclid) are stripped on every request.

MULTI-PROFILE

Isolated data directories per profile — separate bookmarks, history, vault, and session. Create, switch, rename, and delete without ever crossing streams.

SEVEN-PILLAR ARCHITECTURE

The source tree is organized into seven isolated pillars. Each pillar has a single responsibility and communicates over an explicit IPC boundary.

HOW IT WORKS

1. LAUNCH

A single Rust binary opens a native window. The chrome (toolbar, URL bar, tab strip) is injected as a shadow-DOM overlay so no site can tamper with it.

2. RESOLVE

Requests are scrubbed of tracking parameters before the socket opens. In the WebView2 flavor, DNS queries go out over HTTPS to the resolver you picked.

3. BLOCK

The ad blocker runs at the navigation layer, not as a content extension. Known ad networks, pixels, and fingerprinting scripts are cancelled before they fetch.

4. KEEP LOCAL

Bookmarks, history, vault, sessions — every byte lands in your OS config directory. No account, no sync, no backup you didn’t ask for.
