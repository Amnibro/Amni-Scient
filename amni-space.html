WHOLE DRIVE IN ~20 SECONDS • TREEMAP + SUNBURST • AI THAT ASKS FIRST

DOWNLOAD FOR WINDOWS ☕ SUPPORT

See where your disk went. Amni-Space reads the NTFS master file table directly instead of walking folders, so a 930 GB drive with 2.7 million files draws in about twenty seconds.

  • Treemap or sunburst · click to zoom, breadcrumb to jump
  • Finds caches, build output, duplicates and stale copies
  • An AI seat reads the map and proposes a cleanup — you approve every line
  • Deletes go to the Recycle Bin · every run is journalled and undoable

IT READS THE FILE TABLE, NOT THE FOLDERS

Most disk tools open every directory in turn. Amni-Space reads the volume’s own index once and rebuilds the whole tree from it — and it sees files Explorer cannot open, like pagefile.sys.

TWENTY SECONDS

A 930 GB drive with 2,700,000 files maps in about 20 seconds. Any folder, any non-NTFS drive, or a run without admin falls back to a threaded walker automatically.

TWO WAYS TO LOOK

A nested treemap, or a sunburst where the top level is the outer ring and depth runs inward. Color by file type, age, size, or one hue per top-level folder.

FINDS THE FAT

Cache, build output, temp and crash-dump folders. Duplicate groups by name and size. Biggest files, biggest folders, age buckets, and a breakdown by extension.

AN AI THAT ASKS FIRST

Point it at a local model on your own machine, or a Claude, OpenAI, Grok or Gemini key you already have. It reads the map and proposes a plan. You approve it line by line.

NOTHING VANISHES

Deletes go to the Recycle Bin, never unlink. Tidying moves folders to a review folder you purge later. Every applied run is journalled and can be undone.

IT REFUSES BAD IDEAS

Windows, Program Files, .git histories, model weights, checkpoints, backups and keys are off limits at any depth. It will not move a folder that holds a virtual environment, a running program or a scheduled task.

WHAT IT WILL NOT DO

A tool that deletes files has to be honest about its limits. These are enforced in code, not by the model’s good manners.

DeletingRecycle Bin only • blocked if your bin lacks the space, or if it is set to delete immediately
Version control.git, .svn, .hg refused at any depth — history is never regenerable
Irreplaceablemodel weights, bakes, checkpoints, datasets, backups, keys and credentials are never offered
In usea folder holding a venv, a running executable, a service or a scheduled task cannot be moved
The AIproposes only • cannot execute unless you switch autonomy on, and then only under a byte cap
Networkbinds to 127.0.0.1 • your file names leave the machine only if you choose a cloud AI seat

HOW IT WORKS

1. SCAN

Pick a drive and press Scan. On NTFS it reads the master file table directly; everything else falls back to a fast threaded walk. The map draws as soon as it lands.

2. LOOK

Zoom into what is big. Switch to the sunburst when you want the shape of a whole tree at once. Hotspots, Duplicates and Biggest do the obvious hunting for you.

3. PROPOSE

Ask a seat for a plan, or drag folders on the map to build one by hand. You get a before-and-after picture with the numbers that decide whether it is actually better.

4. APPROVE

Dry-run it, untick anything you disagree with, then apply. The map updates instantly. If you change your mind, one button puts everything back.
