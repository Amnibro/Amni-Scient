WHAT IT DOES

When your AI assistant needs to calculate, simulate or crunch data, it usually writes Python, and slow Python means waiting or timing out. Helium Run gives it Helium instead: a compiled language that runs about as fast as C and Rust. The assistant learns Helium from a short guide, writes the program, and Helium Run compiles and runs it on your computer in milliseconds.

FAST

Across 43 test programs written by Claude, the Helium versions ran 9 times faster than Python in total, and 15 to 72 times faster on the heaviest number crunching.

RELIABLE

Claude Haiku, Sonnet and Opus wrote correct Helium for all 43 tasks, the same as in Python and Rust, with at most one fix after reading the compiler’s error.

ON YOUR COMPUTER

Programs compile and run on your own machine. Nothing you or your assistant writes is sent anywhere.

QUESTIONS

What counts as a run?

Each program Helium Run compiles and runs. Reading the Helium guide and checking a program for errors without running it don’t count. The free count resets every day at midnight UTC.

Is it safe?

Programs run on your computer with your own permissions, the same as code an assistant runs in a terminal. Each run stops after its time limit (10 seconds unless the assistant asks for up to 120) and its output is capped at 512 KB. Review what an assistant runs as you would any other code.

What does it send over the internet?

Nothing during normal use. With a paid key it contacts our license server only in the last three days before the key expires, and sends nothing but the key. Your programs, prompts and results stay on your computer.

What is Helium?

A compiled programming language with no garbage collector, built so AI assistants can learn it from one short guide. The compiler is open source under the Apache 2.0 license at github.com/Amnibro/helium.
