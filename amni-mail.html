Install in one line

Needs Python 3.11+ on PATH. The script copies the app to %LOCALAPPDATA%\Amni-Mail and pins a Start Menu shortcut.

iwr -useb https://amni-scient.com/amni-mail/install.ps1 | iex

Or unzip the download and run install.ps1 from inside the folder. Then open Amni-Mail — the browser goes to http://127.0.0.1:8026.
