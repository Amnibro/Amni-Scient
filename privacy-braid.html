BRAID — PRIVACY POLICY

Effective Date: August 14, 2026  |  Last Updated: August 14, 2026

This policy covers Braid, the Windows desktop roundtable published by Amniscient, LLC (“we”, “us”, “our”). Braid is a local orchestrator. It is not an AI provider and it does not sit in the middle of your model traffic.

1. THE SHORT VERSION

Your prompts, answers, files, API keys, and CLI logins never go to Amni-Scient. When you ask the table a question, Braid drives the tools already on your computer — Claude Code, Grok, Gemini CLI, optional API keys, or a local seat (Ollama / bundled Adam). Those seats talk to their vendors (or to nothing, if the seat is local). We do not proxy, store, or train on chat content.

What we do see is the minimum needed to sell a licence: a Stripe checkout (card details stay with Stripe), and later a licence check from the app (key + a machine fingerprint). That is it.

2. WHAT STAYS ON YOUR MACHINE

  • Chats, memory cells, flows, workspace files — written under Braid’s local store / the working directory you pick. We cannot read them.
  • API keys you paste into Braid — stored locally in Braid config. They are sent only to the provider you chose, the same way any other client would.
  • Vendor CLI sessions — Claude, Grok, Gemini, and similar stay signed in through their apps. Braid launches those CLIs; it does not upload their cookies or tokens to us.
  • Licence cache — a signed entitlement file on disk (braid_license.json). The app ships only the public verification key, so that file can be read locally but not forged.

3. WHAT LEAVES THE MACHINE (AMNI-SCIENT)

3.1 Licence activation and re-check

On first activate, and about twice a day afterward, Braid POSTs to our licence server:

  • the licence key you pasted (or a bootstrap token from checkout)
  • a 24-character SHA-256 fingerprint of hostname + MAC (not the raw identifiers)
  • a short hostname for the “this computer” label in the UI

The server returns a signed entitlement (tier, expiry, bound key fingerprint + machine). If you are offline, the cached entitlement keeps working until it expires. Deactivate tells the server to drop that machine binding.

We do not send prompts, transcripts, file paths, or API keys on this channel.

3.2 Payments (Stripe)

Subscriptions and token top-ups are Stripe Checkout. Card number, Apple Pay, Google Pay, and Link stay with Stripe. After payment, Stripe tells us enough to issue or top up a licence (typically email + payment status + amount). See Stripe’s privacy policy.

3.3 Email you send us

If you write amnibro7@gmail.com for teams, a lost key, or support, we keep that thread so we can help. We do not add you to a marketing list from Braid.

3.4 Optional tester reports

The $5 tester tier can send feedback through an in-app reporter. That path strips keys and filesystem paths before anything is packaged. You choose to send it.

4. WHAT LEAVES THE MACHINE (AI VENDORS — NOT US)

This is the part a careful user actually cares about. Braid is a table. The seats still belong to Anthropic, xAI, Google, OpenAI, and whoever else you plug in.

  • Cloud seats receive the prompt Braid built for that turn (your question, plus whatever context you allowed: other seats’ answers, memory cells, file excerpts). Their retention, training, and logging follow your account with that vendor, not this policy.
  • Local seats (Ollama, Adam) stay on-box. Nothing is required to leave.
  • Braid injects launch environment flags so the CLIs skip their own telemetry where they honour it: DO_NOT_TRACK, DISABLE_TELEMETRY, DISABLE_ERROR_REPORTING, OTEL_SDK_DISABLED, Claude non-essential traffic off, Gemini usage statistics off. It can also write the documented opt-outs into Claude’s and Gemini’s local settings files if you use that hardener.
  • Vendor training opt-outs are still account settings (claude.ai privacy, Google account data controls, xAI / OpenAI data controls). A CLI flag cannot rewrite a consumer-plan training toggle. We tell you that in-app; we do not pretend otherwise.

5. WHAT WE DO NOT DO

  • No analytics SDK in the Braid binary. No crash phone-home to us. No product telemetry of chats.
  • No resale or metering of your model tokens. You pay Anthropic / xAI / Google / your API bill yourself.
  • No advertising inside the app.
  • No sale of user data. We do not have your chats to sell.

6. THE WEBSITE (AMNI-SCIENT.COM)

The marketing site that hosts this policy may show Google AdSense on some pages. That is the website, not the Braid exe. Ads there follow Google’s privacy policy. The desktop app contains no AdSense.

7. RETENTION

  • On your disk: until you delete Braid’s store / workspace, or uninstall.
  • Licence records: we keep what we need to honour, revoke, or transfer a paid key (key, machine fingerprints, tier, expiry). Cancel Stripe and we stop issuing fresh entitlements; ask us if you want the licence row deleted.
  • Stripe: Stripe retains payment records under its own policy.
  • Vendor chats: whatever that vendor retains on your account.

8. YOUR RIGHTS

Local data is yours: delete the Braid config directory and workspace. For licence or payment records we hold, email amnibro7@gmail.com. For chat history sitting at Anthropic / xAI / Google / OpenAI, use those providers’ export and delete tools.

9. CHILDREN

Braid is a professional desktop tool. It is not directed at children under 13.
