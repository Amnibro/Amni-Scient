CHAT RELAY

OPTIONAL • DISCOVERY, WEB, SYNC, PUSH • CIPHERTEXT ONLY

INSTALL PUBLIC INSTANCE THE APP

A relay you run yourself, if you want one. The Android app does not need it.

  • Discovery, a web client, multi-device sync, and push
  • Stores ciphertext only
  • Docker, with Caddy for HTTPS
  • One line from amni-scient.com/chat-relay/install.sh

WHAT IT ADDS

Amni-Chat already chats with no server. The relay is for the jobs a phone-only setup doesn’t do: finding people past a QR code, a client in the browser, keeping more than one device in sync, and push.

It stores ciphertext. It does not store the messages in the clear. MLS still ends at the devices.

DISCOVERY

A way to find contacts beyond handing someone a QR code or a link in person.

WEB CLIENT

The same conversation in a browser, on a machine that isn’t the phone.

MULTI-DEVICE

Sync across the devices you add. The phone app alone is the one device you paired.

PUSH

ntfy is the default. Close the app and a new message can still tap the phone.

CIPHERTEXT ONLY

The disk holds what MLS already encrypted. The relay can’t read it back to you.

SELF-HOST

Run it on your own hardware, or use the public instance at chat.amni-scient.com.

ONE LINE

The installer lives at amni-scient.com/chat-relay/install.sh. Docker runs the relay. Caddy does HTTPS.

curl -fsSL https://amni-scient.com/chat-relay/install.sh | sh

That URL is a stub today. Run it and it prints “coming soon” and links this page. The real script ships from the amni-chat repo. The placeholder does not install Docker.

1. THE LINE

Fetch the script and run it. When the real one lands, that same URL is the install.

2. DOCKER + CADDY

The relay is a container. Caddy takes care of the HTTPS certificate in front of it.

3. THE STUB

Until the repo publishes the script, install.sh only tells you it’s coming soon.

NEXT TO HAVEN

You can run the relay on a box that already runs a Haven server. They sit beside each other. Haven stays Haven. This stays ciphertext for Amni-Chat.

Sign in with Haven is optional. If you don’t run Haven, skip it. Push still defaults to ntfy either way.
