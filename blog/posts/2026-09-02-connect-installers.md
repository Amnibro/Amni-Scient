# Amni-Connect installers for Windows and Linux

I was sending people to GitHub and hoping they picked the right file, so the Connect page now has Windows Setup, a Linux AppImage, .deb, and .rpm.

Install on the machine you want to control. The viewer is any browser, phone included, with a room code. Video, audio, and input stay on the WebRTC path. The signaling server never sees frames or keystrokes, and I don't keep logs.

v1.5.16. Linux one-liner if you want it: `curl -fsSL https://raw.githubusercontent.com/Amnibro/Amni-Connect/main/scripts/install-linux.sh | bash`. Windows SmartScreen may ask for More info → Run anyway.
