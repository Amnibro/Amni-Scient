# Amni-Browse on the phone and on Windows

I wanted a browser that only talks to the pages I open, so the product page now has a signed Android APK and a Windows zip.

Android is 0.16.9, system WebView, Android 8+, private by default, tabs and collapsible groups, per-tab favicons. Sideload it from [amni-browse.html](/amni-browse.html).

Windows is 0.13.0, about 6 MB, our chrome on Chromium/WebView2: own frame, tab groups, pinned tabs, find, request-level ad and tracker shield, DNT and Global Privacy Control, DoH, private tabs. There is a one-click Setup that pins Start Menu and Desktop if you want that, or just unzip it.

The Servo desktop build is still experimental, GitHub only. Neither flavor phones home.
