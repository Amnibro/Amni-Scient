# Grok Remote is easier to live with

I use Grok Remote from the phone and the PC, and a few things were making that annoying.

On a wide screen the old chats were getting cut off, so the left rail now lists every conversation and you can scroll it. If that rail is hidden, the ☰ in the chat header brings it back.

I wanted to react to a reply without a row of emoji sitting on every bubble, so a long-press opens a picker, and there's an × plus tap-outside and Escape to close it. If I cancel something I already queued, the text comes back into the box instead of vanishing.

The header has a small bench drawing of Rikku, because that's who I talk to in there.

If you already run Grok Remote, hard-refresh. If you don't, the page is [grok-remote.html](/grok-remote.html).
