# Updates now live on amni-scient.com

I got tired of the homepage being the only place that said anything shipped. You had to scroll tiles and guess, which is a lousy way to follow a studio with this many tools.

So this is the log: [/blog](/blog/). I write a post when something you can actually use lands. File-shuffling stays off this page.

I'll say what I built and why I bothered. Same deal as the product pages: if it has a limit, I'll say the limit.

If you already use Calc or Braid or Learn, this is how you see what changed without hunting GitHub. If you found the site from a link, this is how you can tell I'm still here.

There's [RSS](/blog/rss.xml) if you want it. I won't post every commit. I don't read other people's noise either.

The tools still run in the tab you already have open. None of it watches you.
