# Amni OS 0.4.4 ISO

Under the hood it's Arch + Plasma 6. On top you get a Start menu, a bottom bar, and Steam, Haven, and Amni-Browse already on the dock, with Wine ready for the .exe files you still need.

Control handles drivers and updates, and it asks for a password when it needs one. Restore points show up in GRUB.

New in this one: a Wi-Fi fix, Browse on native Wayland, and an installer that defaults to dual-boot. The image is 5.9 GB, dated 8 Sep 2026.

To install, write it with Rufus or Ventoy and turn Secure Boot off for the stick. Windows stays in the menu. SHA-256 is on the page. Don't want the 5.9 GB from the mirror? There's a torrent and a magnet.

This is the ISO I install. Next up: making the first-boot path boring. Get it from [Amni OS](/amni-os.html).
