A LIVE PHONE COCKPIT FOR GROK BUILD • ONE-QR PAIRING • OPEN SOURCE

📖 GET IT ON GITHUB 📚 SETUP GUIDE ☕ SUPPORT DEVELOPMENT

v1.7.0 • Windows host • any phone or browser • MIT-style licensed

grok plugin install Amnibro/grok-remote@v1.7.0 --trust

YOUR AGENT, IN YOUR POCKET

Grok Build runs on your desk; life doesn't. Grok-Remote puts a live cockpit for the agent on your phone — scan one QR to pair, then send prompts, watch the thinking and every tool call stream in real time, and hop between sessions from the couch, the shop floor or the driveway. The link is engineered to survive the messy parts: Wi-Fi drops, agent restarts, even the server being killed mid-answer.

LIVE STREAM, NOT A TRANSCRIPT

Agent thinking, tool calls with their output, and the final answer arrive as they happen — with catch-up polling so a throttled phone tab never silently freezes.

PAIR WITH ONE QR

Scan once — a 30-day key cookie does the rest. The pairing page only renders on the host machine, and every remote request is key-gated.

MULTI-SESSION, ORGANIZED

Your chats stay yours: apps that drive the same agent (Braid, watchers, loops) are auto-filed into their own buckets by origin, so the active list is only what you actually opened.

A LINK THAT HEALS ITSELF

Agent died? The hub respawns it and re-initializes on the same socket. Server killed? The supervisor restarts it and your phone reconnects in seconds — turns in flight stay on the hub.

SKILLS & SLASH PALETTE

Every installed skill is a tap away. /loop 15m … schedules recurring prompts that keep firing even with the phone in your pocket.

YOUR NETWORK ONLY

Runs on your LAN or private mesh — nothing routes through a third party. Unauthenticated requests get a 401 and a polite pairing page, nothing else.

SEE IT FLY

A simulated session — the same interface, driven by a script so you can watch every feature without installing anything.
