PATTERN

MODEL FEATURE • MODIFY THE PART • TYPE "pattern"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › Modify the part › Pattern

WHAT IT DOES

Copies earlier solid/cut/hole features (or, with body true, the whole part); linear steps dx,dy,dz n times and, with n2 above 1, makes a grid using the row step dx2,dy2,dz2 (total true spreads each step over the whole span); circular with angle 360 spaces them evenly; axis may also be a direction [x,y,z] or the id of a datum_axis feature (its line then replaces ox, oy, oz); curve spaces n copies along the path polyline from its first point (align turns them with the path); offsets places one copy per [x,y,z] offset in pts; skip lists copy numbers to leave out (1 is the original, 2 the first copy, counting along rows first).

Lengths are in the part's units (inches or millimeters). Any number can also be an expression that uses your parameters, such as "t*2".

EXAMPLE

Add it to the open part with the AI assistant's apply_actions tool, or put it in a part file for the headless API:

[ { "add": { "type": "pattern", "body": false, "kind": "linear", "skip": [] } } ]

In a part file:

{ "units": "mm", "features": [ { "id": "f1", "type": "pattern", "body": false, "kind": "linear", "skip": [] } ] }
