ROUTER BIT

MODEL FEATURE • WOODWORKING TOOLING • TYPE "bit"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › Woodworking tooling › Router bit

WHAT IT DOES

A carbide-tipped router bit built from a profile; axis along Z with the tip at z; wings 1-4, carbide thickness ct, hook (rake), shear and relief angles in degrees, bearing none or a standard OD x ID in inches; the cutting edge follows the profile; body true adds a steel wing behind each brazed carbide tip (seat width cw, wing thickness wb), a gullet gul in front of the carbide and an optional anti-kickback limiter ak (maximum chip thickness; bite per revolution = ak x wings).

Lengths are in the part's units (inches or millimeters). Any number can also be an expression that uses your parameters, such as "t*2".
