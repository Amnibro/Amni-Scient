COIL SPRING

MODEL FEATURE • SKETCH FEATURES • TYPE "coil"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › Sketch features › Coil spring

WHAT IT DOES

Helical coil spring of round wire.

Lengths are in the part's units (inches or millimeters). Any number can also be an expression that uses your parameters, such as "t*2".

EXAMPLE

Add it to the open part with the AI assistant's apply_actions tool, or put it in a part file for the headless API:

[ { "add": { "type": "coil", "d": 20, "wire": 2, "pitch": 6, "turns": 5, "x": 0, "y": 0, "z": 0, "axis": "Z", "hand": "right", "op": "add" } } ]

In a part file:

{ "units": "mm", "features": [ { "id": "f1", "type": "coil", "d": 20, "wire": 2, "pitch": 6, "turns": 5, "x": 0, "y": 0, "z": 0, "axis": "Z", "hand": "right", "op": "add" } ] }
