HOLE

MODEL FEATURE • SKETCH FEATURES • TYPE "hole"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › Sketch features › Hole

WHAT IT DOES

Drills into the part from the sketch plane, against its normal; std #4, #6, #8, #10, 1/4, 5/16, 3/8, 1/2 (UNC screws: free-fit clearance, tapped = tap drill, cbore = socket head, csink = 82° flat head) or M2..M20 (ISO 273 medium clearance, ISO 4762 counterbore, ISO 10642 90° countersink) with fit clearance|tapped|cbore|csink sets the sizes in the document units.

Lengths are in the part's units (inches or millimeters). Any number can also be an expression that uses your parameters, such as "t*2".

EXAMPLE

Add it to the open part with the AI assistant's apply_actions tool, or put it in a part file for the headless API:

[ { "add": { "type": "hole", "plane": "XY", "offset": 0, "pts": [ [ 0, 0 ] ], "std": "custom", "thru": true } } ]

In a part file:

{ "units": "mm", "features": [ { "id": "f1", "type": "hole", "plane": "XY", "offset": 0, "pts": [ [ 0, 0 ] ], "std": "custom", "thru": true } ] }
