SHEET METAL

MODEL FEATURE • SKETCH FEATURES • TYPE "sheet"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › Sketch features › Sheet metal

WHAT IT DOES

A bent sheet-metal part: the base outline (shapes, outside dimensions) on the sketch plane becomes a plate t thick (dir + = above the plane, - = below); flanges is a list, each {edge, len, angle, dir, r, then}: edge is front, right, back, left (the longest straight outline edge facing that way), all, or a straight-edge number counted counterclockwise from the lowest edge (0); len is the outside length from the virtual sharp, angle the bend in degrees (default 90, up to 180), dir up or down from the plate, r an optional inside radius (default the feature r); then is a list of more segments {len, angle} after the first, where a positive angle keeps curling the same way (a return or hem, 180 = hem) and a negative angle bends back the other way (a Z or offset); corners butt = where two 90 degree flanges meet, the flange on the longer edge closes the corner and the other stops a gap short of it, open = both stop at their bend reliefs; K is the K-factor for the flat pattern (0 = 0.33 under r < t, 0.4 under 3t, else 0.5); the Make tab and flat DXF unfold the part with bend lines, a bend table, springback and brake force; fails when a flange part is shorter than its bends need.

Lengths are in the part's units (inches or millimeters). Any number can also be an expression that uses your parameters, such as "t*2".

EXAMPLE

Add it to the open part with the AI assistant's apply_actions tool, or put it in a part file for the headless API:

[ { "add": { "type": "sheet", "plane": "XY", "offset": 0, "shapes": [ { "k": "rect", "w": 100, "h": 70 } ], "t": 1.5, "r": 1.5, "dir": "+", "flanges": [ { "edge": "front", "len": 25, "angle": 90, "dir": "up" }, { "edge": "back", "len": 25, "angle": 90, "dir": "up" } ], "K": 0, "corner": "butt" } } ]

In a part file:

{ "units": "mm", "features": [ { "id": "f1", "type": "sheet", "plane": "XY", "offset": 0, "shapes": [ { "k": "rect", "w": 100, "h": 70 } ], "t": 1.5, "r": 1.5, "dir": "+", "flanges": [ { "edge": "front", "len": 25, "angle": 90, "dir": "up" }, { "edge": "back", "len": 25, "angle": 90, "dir": "up" } ], "K": 0, "corner": "butt" } ] }
