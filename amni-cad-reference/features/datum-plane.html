DATUM PLANE

MODEL FEATURE • REFERENCE GEOMETRY • TYPE "datum_plane"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › Reference geometry › Datum plane

WHAT IT DOES

A reference plane that builds no geometry; later features can sketch on it (plane "datum" with datum set to this id) and mirror or split about it; plane picks how it is defined: XY, XZ or YZ (offset along that normal), face (a flat face of the part, face selector, then offset), datum (another datum plane, datum = its id, then offset), points (pts: 3 points [x,y,z] not on one line; the plane passes through them), angle (the plane from, XY|XZ|YZ|a datum plane id, rotated by angle degrees about the datum axis id in axis, right-hand rule) or mid (halfway between two parallel flat faces fa and fb); offset moves the finished plane along its normal.

Lengths are in the part's units (inches or millimeters). Any number can also be an expression that uses your parameters, such as "t*2".

EXAMPLE

Add it to the open part with the AI assistant's apply_actions tool, or put it in a part file for the headless API:

[ { "add": { "type": "datum_plane", "plane": "XY", "offset": 0 } } ]

In a part file:

{ "units": "mm", "features": [ { "id": "f1", "type": "datum_plane", "plane": "XY", "offset": 0 } ] }
