BASIC SOLIDS

  • BoxFeatureAxis-aligned box centered on x,y with its base at z
  • CylinderFeatureCylinder starting at x,y,z going along axis
  • SphereFeatureSolid ball centered on x, y, z with radius r
  • ConeFeatureCone or truncated cone from base radius r1 to top radius r2 over height h along the axis (r2 of 0 gives a sharp tip)
  • TorusFeatureRing with ring radius r1 (center of the tube) and tube radius r2, centered on x, y, z

SKETCH FEATURES

  • ExtrudeFeature2D profile on a plane pushed along the plane normal
  • RevolveFeature2D profile spun around the sketch x or y axis (profile must stay on one side of the axis)
  • HoleFeatureDrills into the part from the sketch plane, against its normal.
  • LoftFeatureBlends between 2+ profiles stacked along the plane normal.
  • SweepFeaturePushes a 2D profile (centered on 0,0) along a 3D polyline path with rounded bends.
  • Coil springFeatureHelical coil spring of round wire
  • RibFeatureA rib or gusset: an open line (pts, 2+ points in sketch coordinates on the sketch plane) is thickened to t across the plane (side both = centered on t…
  • Sketch profilesFeatureThe 2D shapes a sketch feature can use: rectangle, circle, polygon, slot, polyline, text, ellipse, spline (closed), airfoil.

  • ShellFeatureHollows the part inward, removing the open faces

READY-MADE PARTS

  • FanRecipeAxial fan: hub, N twisted airfoil blades (chord taper and pitch twist), optional tip shroud ring, bore with optional keyway and set screw
  • PropellerRecipePropeller: small hub and a few high-pitch tapered airfoil blades, bore with optional keyway and set screw
  • ImpellerRecipeCentrifugal impeller.
  • GearRecipeSpur gear with a true involute tooth profile (full depth, 1.0 m addendum, 1.25 m dedendum), parametric in teeth, module and pressure angle.
  • SprocketRecipeANSI roller chain sprocket.
  • Heat sinkRecipeHeat sink: base plate with plate fins (count and pitch are parameters) or a grid of pin fins, optional corner mounting holes.
  • FlangeRecipeBolt-circle flange: disc, hub, centre bore, N bolt holes on a bolt circle (count is a parameter)
  • Pillow blockRecipePillow block bearing housing.

CONNECT AND INSPECT

  • connection_statusAI toolCheck whether an Amni-CAD browser tab is connected to this assistant and get the pairing code to give the user if it is not.
  • get_design_languageAI toolReturn the reference for the Amni-CAD action language.
  • get_stateAI toolReturn the current model.
  • measureAI toolMeasure the current part.
  • review_designAI toolLook at what you built in ONE call.
  • screenshotAI toolRender the 3D viewport and return it as a JPEG image so you can check the design visually.
  • undoAI toolUndo the last change to the model (the same as Ctrl+Z in the page).
  • redoAI toolRedo the last change that was undone with undo (the same as Ctrl+Y in the page).

HEADLESS HTTP API

  • GET /v1/healthHTTP routeCheck that the local API is running.
  • GET /v1/licenseHTTP routeShow the license the API is using.
  • GET /v1/catalogHTTP routeList everything a job can name: materials, fluids, machines, cutting tools and stock.
  • POST /v1/buildHTTP routeBuild a part from an Amni-CAD document or a STEP or BREP file and measure it.
  • POST /v1/exportHTTP routeExport a part as STEP, STL or BREP.
  • POST /v1/stressHTTP routeRun a static stress, vibration (modal) or heat study.
  • POST /v1/flowHTTP routeRun an air or water flow study around a part.
  • POST /v1/nonlinearHTTP routeRun a nonlinear study: yielding, large deflection or contact.
  • POST /v1/quoteHTTP routePrice a part across machining, printing, sheet metal, molding and more.
  • POST /v1/dxfHTTP routeUnfold a sheet metal part into a flat DXF for cutting.
  • POST /v1/toolpathHTTP routeMake CNC toolpaths and G-code for a part.
  • POST /v1/artHTTP routeTurn a sculpt or scan into a game-ready, textured and rigged asset.
  • POST /v1/art/reviewHTTP routeRender a model from several angles to check it.
