POST /v1/dxf

HEADLESS HTTP API • RUNS ON YOUR OWN COMPUTER • INCLUDED WITH PRO

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › Headless HTTP API › POST /v1/dxf

WHAT IT DOES

Unfold a sheet metal part into a flat DXF for cutting.

The headless API runs on your computer at http://127.0.0.1:41800 after node amnicad.mjs serve. Setup, license tokens and job files are explained on the headless API page.

REQUEST AND RESPONSE

Swipe sideways to see every column.

MethodPathBodyReturns
POST/v1/dxfjob with unitsa flat-pattern DXF

EXAMPLE

node amnicad.mjs run job.json --out result.json {"op":"dxf","doc":{"units":"mm","features":[{"id":"a","type":"box","w":40,"d":30,"h":10}]}}

OTHER ROUTES

  • GET /v1/health Check that the local API is running.
  • GET /v1/license Show the license the API is using.
  • GET /v1/catalog List everything a job can name: materials, fluids, machines, cutting tools and stock.
  • POST /v1/build Build a part from an Amni-CAD document or a STEP or BREP file and measure it.
  • POST /v1/export Export a part as STEP, STL or BREP.
  • POST /v1/stress Run a static stress, vibration (modal) or heat study.
  • POST /v1/flow Run an air or water flow study around a part.
  • POST /v1/nonlinear Run a nonlinear study: yielding, large deflection or contact.
  • POST /v1/quote Price a part across machining, printing, sheet metal, molding and more.
  • POST /v1/toolpath Make CNC toolpaths and G-code for a part.
  • POST /v1/art Turn a sculpt or scan into a game-ready, textured and rigged asset.
  • POST /v1/art/review Render a model from several angles to check it.
