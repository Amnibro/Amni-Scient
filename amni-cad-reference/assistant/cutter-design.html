CUTTER DESIGN

AI ASSISTANT TOOL • MANUFACTURING • MCP NAME "cutter_design"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › AI assistant tools › cutter_design

WHAT IT DOES

Design a woodworking cutter or molding from the profile library and add it to the model: type bit (router bit with shank, bearing, wings, shear, hook, relief, carbide), shaper (cutterhead on a 3/4 or 1-1/4 in spindle, stackable), knife (planer-molder knife ground to the profile corrected for cutting circle, hook angle and projection; also returns the knife and template DXF text), molding (the profile swept along +X or a path), or edge (apply the profile to the selected or given edges of a wood part). Returns the cutting diameter, volume, rim-speed check against the maximum rpm for that diameter (with source), shank engagement, minimum profile radius and, for stick or cope profiles, the numeric rail-and-stile fit. Lengths are in document units except where a field says inches.

The Amni-CAD assistant uses this tool for you when you ask in plain words. Other AI apps (Claude, ChatGPT and any app that speaks MCP) can call it through the Amni-CAD connector while your Amni-CAD tab is open.

ARGUMENTS

Swipe sideways to see every column.

ArgumentTypeRequiredMeaning
typestringyes Choices: bit shaper knife molding edge
profstringyesProfile id from molding_profile (roundover, cove, chamfer, ogee_roman, ogee_classic, cove_bead, beading, rabbet, vgroove, corebox, dovetail, groove, tongue, panel_straight, panel_ogee, panel_cove, stick, cope, finger, lockmiter, drawerlock, gluejoint, casing, base, crown, chairrail, custom).
ppobjectnoDimension overrides for the profile in document units, e.g. {"r":0.25}. custom takes {"pts":[[x,y],...],"bulge":[...]}.
bitobjectnoRouter bit fields: shank (1/4, 1/2, 8mm, 12mm), brg (none, 3/8x1/8, 1/2x3/16, 5/8x1/4, 3/4x1/4, 1x1/4), dia, len, sl, wings, ct, shear, hook, relief.
shaperobjectnoShaper fields: spindle (3/4 or 1-1/4), dia, wings, stack, ct, shear, hook, relief.
knifeobjectnoKnife fields: rc (cutting circle diameter), hook, proj, kt, grip, km, head (auto, top, side), bevel, corr, cp, cd.
rpmnumbernoSpindle speed to check against the rim-speed limit.
addbooleannoAdd or update the feature in the model (default true).
edgesanynoEdge selector for type edge, same as the design language.
dxfbooleanno
unitsstringnoUnit of the DXF text. Choices: in mm
