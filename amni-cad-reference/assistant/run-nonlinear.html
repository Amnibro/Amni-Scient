RUN NONLINEAR

AI ASSISTANT TOOL • SIMULATION • MCP NAME "run_nonlinear"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › AI assistant tools › run_nonlinear

WHAT IT DOES

Run a nonlinear (large-strain, contact) study in the user's browser and return its key results. type "seal": elastomer seal or gasket section squeezed by rigid hardware; returns reaction force, line load (N/mm and lbf/in), contact width, peak contact pressure, peak strain and groove fill. type "forming": sheet-metal dome or channel forming with friction and springback; returns max thinning, plastic strain, punch force, forming-limit margin and springback. type "nonlinear": large-deformation static analysis of the current part with the Stress-tab supports and loads and an optional rigid plate. All lengths mm, forces N, stresses MPa. Takes seconds (2D) to a few minutes (3D).

The Amni-CAD assistant uses this tool for you when you ask in plain words. Other AI apps (Claude, ChatGPT and any app that speaks MCP) can call it through the Amni-CAD connector while your Amni-CAD tab is open.

ARGUMENTS

Swipe sideways to see every column.

ArgumentTypeRequiredMeaning
typestringyes Choices: seal forming nonlinear
paramsobjectnoStudy parameters merged onto the saved ones. seal: shape oring|rect|loops, d (cord diameter), w,h (rect), mode axi|plane, ID (ring inner diameter), groove rect|flat, gw,gd (groove width, depth), squeeze (0-1, flat plates), mat (lsr30..lsr70, epdm70, fkm75, or {kind:"hyper",model:"nh"|"mr"|"yeoh",C10,C01,C20,C30}), mu, n (mesh 10-22). forming: mode axi|plane|3d, tool dome|channel, mat (ss316l, ss304, ti1, ti2, al5052, cu), t (sheet thickness), Rp (punch radius), wp,rp (channel punch half-width, corner radius), Rd,rd (die opening, entry radius), Rb or L (blank radius or half-length), stroke, mu, holder clamp|free, springback (bool), ne,layers (mesh), usePart (3d: the current part is the punch). nonlinear: mat (any of the above), plate (rigid plate travel, 0 = none), plateSide (+Z etc.), steps, res (elements), bodies bonded|contact (parts with several solids: contact meshes each body on its own and lets them press, slide and separate), mu (friction between bodies and on stops). Stress-tab stop supports become rigid walls and disp supports move the face.

{ "name": "run_nonlinear", "arguments": { "type": "…" } }
