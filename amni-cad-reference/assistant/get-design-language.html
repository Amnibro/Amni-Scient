GET DESIGN LANGUAGE

AI ASSISTANT TOOL • CONNECT AND INSPECT • MCP NAME "get_design_language"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › AI assistant tools › get_design_language

WHAT IT DOES

Return the reference for the Amni-CAD action language: feature types and their fields, selectors, parameters, materials, part finishes (the finish action), stress and flow setup, and the list of recipes (one-action generators for hard parts: fan, propeller, impeller, gear, sprocket, heat sink, flange, pillow block). Without topic it returns the modeling essentials (about 20 KB: feature types, profiles, selectors, rules and the recipe list); pass topic for another section (recipes, sketch, assembly, sim, tooling, materials, references, actions or form), or "all" for the full 50 KB reference. Read it once before your first apply_actions call, read a topic only when the task needs it, and use a recipe whenever the part matches one.

The Amni-CAD assistant uses this tool for you when you ask in plain words. Other AI apps (Claude, ChatGPT and any app that speaks MCP) can call it through the Amni-CAD connector while your Amni-CAD tab is open.

ARGUMENTS

Swipe sideways to see every column.

ArgumentTypeRequiredMeaning
topicstringnoSection to return instead of the modeling essentials. recipes returns every recipe with all options and a JSON example; actions only the basic add/set/param/delete actions; all the full reference. Choices: recipes sketch assembly sim tooling materials references actions form all

EXAMPLE CALL

{ "name": "get_design_language", "arguments": { "topic": "sketch" } }
