CASTING PATTERN

AI ASSISTANT TOOL • MANUFACTURING • MCP NAME "casting_pattern"

OPEN AMNI-CAD → ALL FUNCTIONS

Amni-CAD › Reference › AI assistant tools › casting_pattern

WHAT IT DOES

Design a sand-casting pattern (or, with process "permanent", a permanent-mold die) for the current part: shrink allowance, machining allowance on chosen faces, draft, cope and drag halves on a match plate, core prints and sand cores for through holes, a riser sized by Chvorinov's modulus method and Bernoulli choke gating. Returns the summary. Report imperial first.

The Amni-CAD assistant uses this tool for you when you ask in plain words. Other AI apps (Claude, ChatGPT and any app that speaks MCP) can call it through the Amni-CAD connector while your Amni-CAD tab is open.

ARGUMENTS

Swipe sideways to see every column.

ArgumentTypeRequiredMeaning

materialstringnoiron, steel, al, mg, brass, bronze, albronze.

pullanynoPull direction, as for mold_design.
assemblybooleannoAlso build an assembly of the pattern pieces.
step_pathstringnoWrite the pattern solids as STEP to this path.
drawings_pathstringnoWrite drawings of the pattern halves to this path (PDF).
overwritebooleanno
