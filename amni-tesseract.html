AMNI-TESSERACT

EXPERIMENTAL SHADOW MODE • LINUX INTEGRITY AND AUDIT • DOES NOT BLOCK

SOURCE ON GITHUB WHAT IT WATCHES

WHAT IT IS

Amni-Tesseract is an open-source Linux tool for integrity and audit. It is experimental. It runs in shadow mode: it records what changed and who touched it, and it does not block the action. The license is Apache-2.0.

SIGNED BASELINE

A signed baseline of system files, then a drift recheck against that baseline.

FOUR-AXIS AUDIT

Each access is recorded on four axes: who, what, how, and when.

NETWORK WATCHDOG

Flags unexpected outbound connections. It reports them. It does not drop them.

eBPF TRACEPOINTS

The watch uses eBPF tracepoints on Linux. There is no second agent in user space rewriting policy.

THREAT MODEL

The threat model assumes passwords and the TPM are already compromised. A signature check that trusts those alone is not the control. The baseline, the drift recheck, and the four-axis record are what the operator reviews after the fact.

  • Audit only. A finding does not stop the process, the file write, or the connection.
  • Shadow mode is the current mode. There is no enforce switch in this release.
  • Signing-key protection is future work. The key that signs the baseline is not yet held in a way this page can call protected.

WHAT WAS MEASURED

On a test virtual machine, one four-axis evaluation took about 6 to 7 nanoseconds. Rechecking 13 files took about 45 milliseconds. Those are measurements from that run, not a guarantee on other hardware.

STATUS

Experimental. Read the repository before you put it on a machine you care about. It will not stop an attacker who is already on the box. It gives you a record to read.

Does it block anything?

No. Shadow mode is audit-only. Unexpected outbound connections are flagged, not dropped. File changes are recorded against the signed baseline, not rolled back.

Where is the source?

github.com/Amnibro/amni-tesseract, Apache-2.0.

What is not done yet?

Signing-key protection is future work. Until that exists, treat the baseline signing key as unprotected.
