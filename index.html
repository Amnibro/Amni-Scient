How this gets built

Just me: one engineer, no funding, and one rule about what leaves your machine.

Nothing phones home

The browser has no telemetry, the learning games collect nothing, and the AI assistant runs on your own GPU. Where something really does need a server, like messaging or licence checks, it's a server you can run yourself. And every product spells out exactly what data it touches in its own privacy policy, not one blanket page.

The hardware gets used

I put the graphics card and parallel code to work wherever the job deserves it, on the desktop and in the browser. A galaxy of 160,000 stars and a beam calculator both belong in a browser tab, and both run there!

It has to survive contact

These are working tools, so the calculators cite the standard they follow and ship a worked example you can check by hand. The architecture is documented, the changes are logged, and anything that claims a number can show you where that number came from.
