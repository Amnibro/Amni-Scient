# Legacy Rust web builds

These are the previous browser builds of Amni that used to live at `/game/`, `/game/v2/`, and `/game/revamp/`. They were moved here on 2026-11-20 when the Helium WebGPU build took over `https://amni-scient.com/game/`.

- `/game/legacy-rust/` — classic landing page
- `/game/legacy-rust/v2/` — older v2 remake
- `/game/legacy-rust/revamp/` — Rust revamp preview

To roll the site back, copy this folder's contents up to `/game/` (and restore the previous `_redirects` / `_headers` / nav links) or revert the deploy commit.
