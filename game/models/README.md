# Amni Model Skins (web)

Drop flat-colored .glb files here to skin the game on the web build:
player.glb, beetle.glb, pillbug.glb, aphid.glb, grass.glb, rock.glb

Same names under Amni-Game/assets/models/ skin the native build.
Models must use vertex or material base colors (textures are not sampled).
Missing files fall back to the built-in procedural meshes.
