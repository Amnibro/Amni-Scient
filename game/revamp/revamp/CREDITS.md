# Amni revamp art: credits and license audit

Every third-party source used in `assets/revamp/` is CC0 1.0 (public domain dedication,
https://creativecommons.org/publicdomain/zero/1.0/). No attribution is legally required; it is
given here anyway. Everything not listed below is original procedural work generated by
`tools/revamp_art/` for this project.

The source packs are not committed. `tools/revamp_art/fetch_sources.sh` downloads them into a
cache directory and prints the CC0 line from each pack's license file.
