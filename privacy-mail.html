Amni-Mail privacy

Amni-Mail is a desktop client that runs on your computer. Amniscient, LLC does not operate a mail server for it and does not receive your messages.

What stays on the machine

Message bodies, headers, attachments, contacts, calendar events, rules, and search indexes live in a local SQLite file under the install directory. Passwords and OAuth tokens are stored in an encrypted credentials file keyed on that machine.

What leaves the machine

IMAP and SMTP traffic goes to the mail host you configure (Google, Microsoft, Fastmail, and so on). If you paste your own OAuth client, token exchange goes to that provider. Optional AI features call only the URL you set (default a local server). The amni-scient.com website is not in that path.

What we do not do

No accounts at amni-scient. No analytics. No crash reports. No advertising identifiers. The download zip and install script are static files.
